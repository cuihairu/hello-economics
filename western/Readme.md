# 西方经济学

这门课不是在背零散概念，而是在回答一个总问题：

**市场中的消费者、厂商和政府，怎样通过价格、产出和政策相互作用，决定资源配置和经济波动。**

如果把整门课压成问题链，大致可以分成三层：

1. 微观部分：价格怎么形成，消费者和厂商怎么决策，市场什么时候有效。
2. 宏观部分：总产出、就业、利率和物价怎么共同决定。
3. 政策部分：财政政策、货币政策和政府干预什么时候有效、什么时候有限。

## 一、先抓这门课的总问题

- 为什么需求曲线向右下方倾斜，弹性为什么重要。
- 厂商怎样在成本约束下实现利润最大化。
- 完全竞争、垄断和市场失灵分别意味着什么。
- 国民收入、利率和价格水平怎样在宏观上形成均衡。
- 财政政策和货币政策怎样影响总需求、总供给和经济增长。
