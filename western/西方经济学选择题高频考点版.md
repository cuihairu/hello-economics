## 二、按题型归并的高频考点

### 1. 需求、供给与均衡

高频问法：

- 需求曲线右移/左移，价格和数量怎么变
- 供给曲线右移/左移，价格和数量怎么变
- 需求变动和需求量变动的区别
- 供给变动和供给量变动的区别

必记：

- 需求增加：均衡价格上升，均衡数量增加
- 需求减少：均衡价格下降，均衡数量减少
- 供给增加：均衡价格下降，均衡数量增加
- 供给减少：均衡价格上升，均衡数量减少

易混点：

- 价格变动引起的是**需求量变动**，不是需求变动
- 非价格因素变动引起的是**需求变动**

### 2. 弹性与总收益

高频问法：

- `Ed` 大于 1、小于 1、等于 1 时总收益如何变化
- 价格提高后需求如何变化
- 需求价格弹性、收入弹性、交叉弹性的符号判断

必记：

- `|Ed|>1`：降价增收
- `|Ed|<1`：提价增收
- `|Ed|=1`：总收益不变

易混点：

- 需求价格弹性通常为负，比较时看绝对值
- 正常品收入弹性大于 0，低档品收入弹性小于 0
- 互补品交叉弹性小于 0，替代品交叉弹性大于 0

### 3. 成本、产量与边际关系

高频问法：

- 当边际产量大于平均产量时，平均产量怎样变
- 当边际成本小于平均成本时，平均成本怎样变
- `MC` 与 `AC`、`AVC` 的关系
- 边际产量等于 0 时总产量如何变化

必记：

- `MP>AP`：`AP` 上升
- `MP<AP`：`AP` 下降
- `MC<AC`：`AC` 下降
- `MC>AC`：`AC` 上升
- `MC` 与 `AC` 相交于 `AC` 最低点
- 边际产量为 0 时，总产量达到最大值

### 4. 市场结构

高频问法：

- 完全竞争、完全垄断、垄断竞争、寡头的区别
- 垄断竞争市场的特征
- 自然垄断形成原因
- 价格歧视属于谁的行为

必记：

- 完全竞争：厂商很多、产品同质、进退自由
- 完全垄断：唯一厂商、无替代品、进入壁垒高
- 垄断竞争：厂商多、产品有差别、进退较自由
- 寡头：少数厂商、相互依存明显

易混点：

- 垄断竞争不是完全竞争
- 有产品差别但厂商很多，通常先想到垄断竞争
- 自然垄断的核心不是“只有一家厂商”，而是**一家供给成本更低**

### 5. 货币需求、货币供给与货币政策工具

高频问法：

- 货币政策三大一般性工具
- 凯恩斯货币需求三大动机
- 货币供给内生性/外生性
- 公开市场业务买入或卖出证券的效果

必记：

- 一般性货币政策工具：法定准备金率、再贴现政策、公开市场业务
- 凯恩斯三大动机：交易、预防、投机
- 买入证券：投放基础货币，货币供给增加
- 卖出证券：回笼基础货币，货币供给减少

易混点：

- 信贷配给、不动产信用控制属于选择性工具，不是一般性工具
- 货币供给外生性强调中央银行控制，内生性强调体系内部多因素决定

### 6. `IS-LM` 与宏观政策效果

高频问法：

- 货币供给增加，`IS` 还是 `LM` 变
- 政府购买增加，利率和收入怎么变
- 扩张性财政政策与货币政策的方向判断
- 流动偏好陷阱下哪种政策更有效

必记：

- 政府购买增加：`IS` 右移，`Y` 上升，`r` 上升
- 货币供给增加：`LM` 右移，`Y` 上升，`r` 下降
- 流动偏好陷阱：货币政策弱，财政政策强

易混点：

- 财政政策动 `IS`
- 货币政策动 `LM`

### 7. 总需求、总供给与通货膨胀

高频问法：

- 总需求曲线为什么向右下方倾斜
- 短期总供给和长期总供给的区别
- 需求拉动型和成本推进型通货膨胀的区别
- 货币供给增加对产出和价格的影响

必记：

- 价格下降 -> 实际货币供给上升 -> `LM` 右移 -> `Y` 上升 -> AD 向右下倾
- 短期总供给曲线向右上方倾斜
- 长期总供给曲线近似垂直
- 需求拉动：总需求过快增长
- 成本推进：成本上升推动价格上涨

### 8. 经济增长理论

高频问法：

- 哈罗德-多马模型的核心关系式
- 新古典增长模型稳态下人均资本增长率是多少
- 人口增长率上升对稳态人均资本有什么影响
- Cobb-Douglas 生产函数中的收入份额

必记：

- 哈罗德-多马模型：`G=s/v`
- 新古典增长模型稳态：人均资本增长率 = 0
- 人均产出增长率 = 0
- 总产出增长率通常等于人口增长率（不考虑技术进步时）
- 若 `Y=K^\alpha L^{1-\alpha}`，资本收入份额为 `\alpha`

## 四、最常见陷阱题

### 1. 弹性前面的负号

题目常故意把 `Ed` 算成负数后直接比较大小。  
正确做法：判断总收益变化时看 `|Ed|`。

### 2. 价格上升到底是谁变了

价格本身变化只会导致沿曲线移动，不会导致曲线移动。

### 3. 货币政策动哪条线

- 财政政策先想到 `IS`
- 货币政策先想到 `LM`

### 4. 自然垄断不是“唯一厂商”四个字

关键是规模经济和平均成本持续下降。

### 5. 流动偏好陷阱不是财政政策失效

恰好相反，是扩张性货币政策效果弱，财政政策更有效。

### 6. 名义利率不等于实际利率

关系式：

$$
i=r+\pi
$$

其中 `i` 为名义利率，`r` 为实际利率，`\pi` 为通货膨胀率。

## 五、按年份看选择题高频点

### 2010-2012

- 弹性
- 垄断基础判断
- 总需求曲线
- 名义利率与实际利率

### 2013-2017

- 货币政策规则
- 流动偏好陷阱
- 自然垄断
- 增长理论

### 2018-2021

- 总供给
- 货币供给内生性
- 垄断竞争市场
- 新经济增长理论 / 增长模型

### 2022-2025

- 流动偏好陷阱
- 货币供给内生性和外生性
- 新古典增长模型
- 凯恩斯与弗里德曼货币需求理论相关概念

## 六、考前怎么刷选择题

### 第一轮

只刷高频知识点，不追求全覆盖。优先刷：

1. 货币理论
2. 市场结构
3. 弹性
4. `IS-LM`

### 第二轮

专门整理易混点，一组一组对比记忆。

### 第三轮

只看陷阱题和错题，不再重看会做的基础题。

## 七、最后 2 分钟看什么

最后只扫这些判断：

1. 财政政策动 `IS`，货币政策动 `LM`
2. `|Ed|>1` 降价增收，`|Ed|<1` 提价增收
3. `MP>AP`，`AP` 上升；`MC<AC`，`AC` 下降
4. 垄断竞争：厂商多、产品差别、进退自由
5. 流动偏好陷阱：货币政策弱，财政政策强
6. 短期总供给上倾，长期总供给垂直
7. 稳态时人均资本增长率 = 0
8. 哈罗德-多马：`G=s/v`

把这 8 条盯住，选择题失分会明显少很多。
