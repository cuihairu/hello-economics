# 西方经济学题型索引

这份文件只回答两个问题：

1. 不同题型，应该去哪份资料复习。
2. 如果是计算题，拿到题以后第一步先写什么。

## 二、计算题拿到题先写什么

### 1. 均衡价格与均衡数量题

识别关键词：

- 均衡价格
- 均衡数量
- 市场出清

先写：

$$Q_d(P)=Q_s(P)$$

标准步骤：

1. 写需求函数和供给函数。
2. 令二者相等。
3. 先解均衡价格，再回代求均衡数量。

### 2. 弹性题

识别关键词：

- 点弹性
- 弧弹性
- 提价还是降价
- 总收益变化

先写：

$$E_d=-\frac{dQ}{dP}\cdot\frac{P}{Q}$$

标准步骤：

1. 将需求函数整理成 $Q=f(P)$。
2. 求 $\frac{dQ}{dP}$。
3. 代入指定点的 $P,Q$。
4. 判断和 1 的大小关系。

### 3. 消费者最优题

识别关键词：

- 效用最大化
- 最优消费组合
- 预算约束

先写：

$$P_1X_1+P_2X_2=I$$

再写：

$$\frac{MU_1}{P_1}=\frac{MU_2}{P_2}$$

或：

$$MRS_{12}=\frac{P_1}{P_2}$$

标准步骤：

1. 写预算约束。
2. 写最优条件。
3. 联立求最优消费量。

### 4. 厂商最优产量与价格题

识别关键词：

- 利润最大化
- 最优产量
- 最优价格
- 垄断厂商

先写：

$$MR=MC$$

但之前通常要先推：

$$TR=P(Q)\cdot Q$$

$$MR=\frac{dTR}{dQ}$$

标准步骤：

1. 若给需求函数，先推反需求函数。
2. 写总收益。
3. 求边际收益。
4. 联立 $MR=MC$ 求产量。
5. 再回代求价格。

### 5. 要素最优组合题

识别关键词：

- 最优要素组合
- 成本最小化
- 既定产量
- 等产量曲线

先写：

$$\frac{MP_L}{r_L}=\frac{MP_K}{r_K}$$

或：

$$MRTS_{LK}=\frac{r_L}{r_K}$$

标准步骤：

1. 求 $MP_L,MP_K$。
2. 写最优条件。
3. 联立成本约束或产量约束。

### 6. 要素使用最优题

识别关键词：

- 边际产品价值
- 边际收益产品
- 边际要素成本
- 劳动雇佣量

先写：

$$MRP=MFC$$

若完全竞争产品市场，可写：

$$VMP=P\cdot MP$$

标准步骤：

1. 判断是完全竞争还是不完全竞争。
2. 写 $VMP$ 或 $MRP$。
3. 联立 $MRP=MFC$。

### 7. 一般均衡或帕累托最优题

识别关键词：

- 帕累托最优
- 一般均衡
- 埃奇沃斯框图
- 瓦尔拉斯定律

先写：

交换最优：

$$MRS_{XY}^A=MRS_{XY}^B$$

生产最优：

$$MRTS_{LK}^X=MRTS_{LK}^Y$$

交换与生产同时最优：

$$MRS_{XY}=MRT_{XY}$$

标准步骤：

1. 先判断题目是在问交换、生产还是两者同时。
2. 再写对应边际条件。

### 8. 简单国民收入决定题

识别关键词：

- 均衡国民收入
- 两部门经济
- 投资乘数
- 边际消费倾向

先写：

$$Y=C+I$$

或：

$$I=S$$

标准步骤：

1. 代入消费函数和投资函数。
2. 解均衡收入。
3. 再求储蓄、乘数或缺口。

### 9. 三部门或财政政策题

识别关键词：

- 政府购买
- 税收
- 平衡预算乘数

先写：

$$C=\alpha+\beta(Y-T_0)$$

以及：

$$Y=C+I+G$$

标准步骤：

1. 先写可支配收入和消费函数。
2. 再写总支出均衡。
3. 分析 $G,T$ 变化如何影响 $Y$。

### 10. IS 曲线题

识别关键词：

- IS 曲线
- 产品市场均衡

先写：

$$S(Y)=I(r)$$

标准步骤：

1. 先由消费函数推出储蓄函数。
2. 写产品市场均衡。
3. 整理成 $Y=a-br$。

### 11. LM 曲线题

识别关键词：

- LM 曲线
- 货币市场均衡
- 流动偏好

先写：

$$L(Y,r)=m$$

标准步骤：

1. 写货币需求函数。
2. 等于货币供给。
3. 整理成 $Y=c+dr$。

### 12. IS-LM 联立题

识别关键词：

- 产品市场和货币市场一般均衡
- 均衡利率
- 均衡收入

先写：

$$
\begin{cases}
S(Y)=I(r) \\
L(Y,r)=\frac{M}{P}
\end{cases}
$$

标准步骤：

1. 先分别列出 IS 和 LM 方程。
2. 再联立求均衡收入与利率。
3. 最后分析财政政策或货币政策冲击。

### 13. AD-AS 题

识别关键词：

- 总需求
- 总供给
- 价格总水平
- 税收或货币冲击

先写：

`AD` 来自 `IS-LM` 联动，`AS` 反映价格与总产出关系。

标准步骤：

1. 先判断冲击来自需求侧还是供给侧。
2. 再分析 `AD` 或 `AS` 哪条曲线移动。
3. 最后说明产出和价格如何变化。

### 14. 新古典增长模型题

识别关键词：

- 稳态
- 人均资本
- 人均产出
- 黄金律

先写：

$$\Delta k=sf(k)-(n+\delta)k$$

稳态写：

$$\Delta k=0$$

标准步骤：

1. 写人均资本积累方程。
2. 令 $\Delta k=0$ 求稳态。
3. 再求稳态人均产出和增长率。
4. 若问黄金律，写 $f'(k)=n+\delta$。

### 15. 限价、补贴、税负分担题

识别关键词：

- 最高限价
- 单位补贴
- 税负分担
- 短缺量

先写：

$$Q_d(P)=Q_s(P)$$

若题目已经指定价格，就分别代入 `Q_d` 与 `Q_s`。

标准步骤：

1. 先判断是否需要原均衡。
2. 若有管制价格，分别求 `Q_d` 和 `Q_s`。
3. 若问短缺，写 `Q_d-Q_s`。
4. 若有补贴，先改供给函数，再求新均衡。

## 三、最后怎么用这份索引

如果你现在时间不多，直接按这个顺序：

1. 先看 [西方经济学考前一页纸总纲](西方经济学考前一页纸总纲.md)。
2. 再按自己的弱项去刷对应题型资料。
3. 计算题一定至少再过一遍 [西方经济学计算题考前速背版](西方经济学计算题考前速背版.md)。
4. 非计算题里，最值得优先背的是名词解释、简答题、论述题各自的高频清单。
