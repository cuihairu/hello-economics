# IS-AS 模型通俗讲解

> **用生活中的例子理解宏观经济学的核心工具**

---

## 前言：为什么需要 IS-AS 模型？

想象你是一个国家的"经济CEO"。你需要回答三个问题：

1. **经济状况如何？** —— 产出（Y）是多少？
2. **价格合理吗？** —— 物价水平（P）是高还是低？
3. **出了问题怎么办？** —— 用什么政策调节经济？

IS-AS 模型就是回答这些问题的一套"决策工具包"。

---

## 一、模型框架：三个核心角色

IS-AS 模型中有三个"主角"：

| 角色 | 英文 | 含义 | 简单理解 |
|------|------|------|----------|
| **IS曲线** | Investment-Saving | 产品市场均衡 | **"钱怎么花"** —— 买东西和投资 |
| **AS曲线** | Aggregate Supply | 总供给曲线 | **"能生产多少"** —— 工厂产能 |
| **AD曲线** | Aggregate Demand | 总需求曲线 | **"想买多少"** —— 从IS-LM推导出来 |

> **注意**：你可能见过"IS-LM模型"，那是只考虑产品市场和货币市场。而**IS-AS模型加入了价格因素**，更接近现实。

---

## 二、IS曲线：产品市场的"买买买"线

### 2.1 什么是IS曲线？

**一句话**：IS曲线告诉我们"在不同利率下，经济能实现多少交易平衡"。

**通俗比喻**：
- 把经济想象成一个**大集市**
- **I（投资）** = 商家愿意投入多少资金扩大生意（取决于利率高低）
- **S（储蓄）** = 老百姓愿意存多少钱（取决于收入多少）
- **IS均衡** = 商家想花的钱 = 老百姓存下的钱

### 2.2 IS曲线为什么向右下倾斜？

```
利率 ↓ → 借款便宜 → 投资增加 → 产出增加 → 收入增加
利率 ↑ → 借款贵了 → 投资减少 → 产出减少 → 收入减少
```

**图形**：
```
利率
  ↑
  |    IS曲线
  |   ↘  （向右下方倾斜）
  |     ↘
  |       ↘
  +------------→ 产出/收入
```

**生活例子**：
- 银行利率从 5% 降到 3% → 公司更愿意贷款开新厂 → 就业增加 → 大家收入增加

---

## 三、AD曲线：总需求——"大家都想买多少"

### 3.1 AD曲线从哪里来？（数学证明）

AD曲线是**从IS-LM模型推导出来的**。

**直观理解**：
```
步骤1：价格P上升 → 钱变得"不值钱"了
步骤2：实际货币供给(M/P)下降 → 大家手里的"购买力"减少
步骤3：LM曲线左移 → 利率上升
步骤4：利率上升 → 投资下降 → 总需求下降
```

---

### 3.2 AD曲线的数学推导（核心证明）

**第一步：写出IS-LM方程组**

IS方程（产品市场均衡）：
$$I(r) = S(Y) = Y - C(Y)$$

展开消费函数 $C = a + bY$（a为自发消费，b为边际消费倾向）：
$$I(r) = Y - a - bY$$
$$I(r) = -(a) + (1-b)Y$$

设投资函数为 $I(r) = e - dr$（e为自发投资，d为投资对利率的敏感系数）：
$$e - dr = -(a) + (1-b)Y$$

整理得IS方程：
$$Y = \frac{a + e}{1-b} - \frac{d}{1-b}r \quad \text{......(1)}$$

---

LM方程（货币市场均衡）：
$$\frac{M}{P} = L_1(Y) + L_2(r)$$

设货币需求函数为 $L = kY - hr$（k为交易需求系数，h为投机需求系数）：
$$\frac{M}{P} = kY - hr$$

整理得LM方程：
$$Y = \frac{h}{k}r + \frac{1}{k} \cdot \frac{M}{P} \quad \text{......(2)}$$

---

**第二步：从方程(1)中解出r**

$$Y = \frac{a + e}{1-b} - \frac{d}{1-b}r$$

$$\frac{d}{1-b}r = \frac{a + e}{1-b} - Y$$

$$r = \frac{a + e - (1-b)Y}{d} \quad \text{......(3)}$$

---

**第三步：将r代入LM方程**

将(3)代入(2)：
$$Y = \frac{h}{k} \cdot \frac{a + e - (1-b)Y}{d} + \frac{1}{k} \cdot \frac{M}{P}$$

$$Y = \frac{h(a + e)}{kd} - \frac{h(1-b)}{kd}Y + \frac{M}{kP}$$

将含Y的项移到左边：
$$Y + \frac{h(1-b)}{kd}Y = \frac{h(a + e)}{kd} + \frac{M}{kP}$$

$$Y \left(1 + \frac{h(1-b)}{kd}\right) = \frac{h(a + e)}{kd} + \frac{M}{kP}$$

$$Y \left(\frac{kd + h(1-b)}{kd}\right) = \frac{h(a + e)P + Md}{kPd}$$

$$Y = \frac{kd}{kd + h(1-b)} \cdot \frac{h(a + e)P + Md}{kPd}$$

$$Y = \frac{h(a + e)P + Md}{P[kd + h(1-b)]}$$

$$Y = \frac{h(a + e)}{kd + h(1-b)} + \frac{Md}{[kd + h(1-b)]P} \quad \text{......(4)}$$

---

**第四步：分析AD函数**

令 $\alpha = \frac{h(a + e)}{kd + h(1-b)}$，$\beta = \frac{Md}{kd + h(1-b)}$

则总需求函数为：
$$Y = \alpha + \frac{\beta}{P}$$

**结论**：由于 $\beta > 0$，当P↑时，Y↓ —— **AD曲线向右下方倾斜**

---

### 3.3 AD曲线的形状

### 3.2 AD曲线的形状

```
价格水平P
  ↑
  |    AD曲线
  |   ↘  （向右下方倾斜）
  |     ↘
  |       ↘
  +------------→ 总需求Y
```

**生活例子**：
- 物价整体上涨10% → 你工资没变 → 购买力下降 → 少买东西

## 四、AS曲线：总供给——"社会能生产多少"

### 4.1 短期AS曲线的数学推导（向右上倾斜）

**核心假设**：**货币工资刚性**（工资W固定，只能涨不能跌）

---

**第一步：生产函数**

设宏观生产函数为：
$$Y = f(N, \bar{K})$$

其中：Y为产出，N为就业量，$\bar{K}$为固定资本

通常使用柯布-道格拉斯形式：
$$Y = AN^{\alpha}$$

A为技术系数，α为劳动产出弹性（0 < α < 1）

**结论**：Y与N正相关，N↑ → Y↑

---

**第二步：劳动市场均衡**

**劳动需求函数**（厂商利润最大化）：
厂商雇佣劳动直到边际产品价值等于实际工资：
$$W/P = MP_N = \frac{dY}{dN} = \alpha A N^{\alpha-1}$$

解出劳动需求量：
$$N^d = \left(\frac{\alpha A P}{W}\right)^{\frac{1}{1-\alpha}} \quad \text{......(1)}$$

**劳动供给函数**：
$$N^s = N^s(W/P)$$

工人根据实际工资决定是否工作，实际工资越高，劳动供给越多。

---

**第三步：工资刚性的关键作用**

在**短期**，货币工资W固定（有向下刚性）

当价格P上升时：
- 实际工资 $W/P$ 下降
- 由(1)式可知：$N^d$ 增加（厂商愿意多雇人）
- 就业量N由需求决定（$N = N^d$）

将(1)代入生产函数：
$$Y = A \left[\left(\frac{\alpha A P}{W}\right)^{\frac{1}{1-\alpha}}\right]^{\alpha}$$

$$Y = A \left(\frac{\alpha A}{W}\right)^{\frac{\alpha}{1-\alpha}} \cdot P^{\frac{\alpha}{1-\alpha}}$$

令 $\gamma = A \left(\frac{\alpha A}{W}\right)^{\frac{\alpha}{1-\alpha}}$，$\theta = \frac{\alpha}{1-\alpha} > 0$

则**短期总供给函数**为：
$$Y = \gamma \cdot P^{\theta}$$

**结论**：由于 $\theta > 0$，当P↑时，Y↑ —— **短期AS曲线向右上方倾斜**

---

**图形推导过程**：

```
第一步：价格P上升
第二步：实际工资W/P下降（W固定）
第三步：劳动需求Nd增加

实际工资 W/P
      ↑
      |     Nd（劳动需求曲线）
      |    ＼
      |     ＼  P↑ → W/P↓ → 沿曲线向右下移动
      |      ＼
      |       ＼
      +--------→ 就业量N
               N↑

第四步：就业量N增加 → 产出Y增加

产出Y
      ↑
      |       Y=f(N)（生产函数）
      |      ／
      |     ／  N↑ → Y↑
      |    ／
      |   ／
      +--------→ 就业量N

综合：P↑ → Y↑（AS曲线向右上倾斜）
```

---

### 4.2 长期AS曲线：垂直线

**核心假设**：货币工资W可以**自由调整**

**推导过程**：

当价格P上升时：
1. 实际工资 $W/P$ 下降
2. 工人要求提高货币工资W
3. 货币工资W上升，直到实际工资恢复到均衡水平
4. 就业量N回到充分就业水平 $N^*$
5. 产出Y回到潜在产出水平 $Y^*$

**数学表达**：

长期劳动市场均衡：
$$N^d\left(\frac{W}{P}\right) = N^s\left(\frac{W}{P}\right) = N^*$$

产出由生产函数决定：
$$Y^* = f(N^*, \bar{K}) = \text{常数}$$

**结论**：无论P如何变化，Y始终等于 $Y^*$ —— **长期AS曲线是垂直线**

**生活例子**：
- 你月薪3000元，物价涨了，但工资还是3000
- 老板发现你的"实际工资"便宜了 → 决定加班生产

**图形**：
```
价格水平P
  ↑
  |          短期AS曲线
  |         ↗  （向右上方倾斜）
  |       ↗
  |     ↗
  +------------→ 产出Y
```

### 4.2 长期AS曲线：垂直线

**核心观点**：长期看，工资会调整，经济回到"充分就业"

**逻辑**：
```
价格持续上涨 → 工人要求涨工资 → 实际工资恢复 → 产量回到潜在水平
```

**图形**：
```
价格水平P
  ↑
  |    长期AS曲线
  |          |  （垂直线）
  |          |
  |          |
  +----------|--→ 产出Y
         Y*（潜在产出）
```

**生活例子**：
- 物价涨了一年后，你终于和老板谈好涨工资
- 你的工作量回到正常水平

## 五、IS-AS模型完整分析：两个市场的对话

### 5.1 完整框架图

```
        IS曲线          LM曲线
    (产品市场均衡)   (货币市场均衡)
           \           /
            \         /
             \       /
              \     /
               \   /
                \ /
              AD曲线
           (总需求曲线)
                 |
                 | 交叉
                 |
              AS曲线
           (总供给曲线)
                 |
              均衡点（Y*, P*）
```

### 5.2 均衡状态

当 **AD = AS** 时，经济达到均衡：
- 总产出 = Y*（均衡产出）
- 价格水平 = P*（均衡价格）

## 六、政策分析：IS-AS模型的实际应用

### 6.1 财政政策：移动IS曲线

**扩张性财政政策**（政府多花钱、减税）：
```
IS曲线右移 → AD曲线右移 → 产出增加，价格上升
```

**生活例子**：
- 政府修高铁 → 钢铁水泥需求增加 → 工厂加班生产 → 就业增加

**政策效果**：
- **短期**：产出↑，价格↑
- **长期**：只有价格↑，产出回到潜在水平

### 6.2 货币政策：移动LM曲线

**扩张性货币政策**（央行多印钱）：
```
LM曲线右移 → 利率下降 → 投资增加 → AD曲线右移
```

**生活例子**：
- 央行降低利率 → 房贷便宜了 → 大家买房 → 楼市兴旺

### 6.3 供给冲击：移动AS曲线

**不利供给冲击**（如油价暴涨）：
```
AS曲线左移 → 产出下降，价格上升 → "滞胀"
```

**生活例子**：
- 国际油价翻倍 → 运输成本涨 → 工厂减产 + 商品涨价

## 七、短期 vs 长期：关键区别

| 特征 | 短期 | 长期 |
|------|------|------|
| AS曲线形状 | 向右上倾斜 | 垂直 |
| 工资调整 | 有刚性，难调整 | 充分调整 |
| 政策效果 | 财政/货币政策有效 | 财政/货币政策只影响价格 |
| 产出决定 | 需求主导 | 供给能力主导 |

**核心洞见**：
> **"长期看，经济总是回到充分就业；短期看，政策可以影响产出"**

## 九、与IS-LM模型的区别

| 比较项 | IS-LM模型 | IS-AS模型 |
|--------|-----------|-----------|
| 假设 | 价格P固定 | 价格P可变 |
| 坐标轴 | (Y, r) | (Y, P) |
| 适用场景 | 短期分析 | 短期+长期分析 |
| 现实性 | 较简化 | 更接近现实 |

**升级路径**：
```
简单国民收入决定理论
        ↓ 加入货币市场
     IS-LM模型
        ↓ 加入价格变量
    IS-AS模型
```

## 十、典型考题思路

### 题型1：推导AD曲线
**解题步骤**：
1. 写出IS方程：Y = C(Y-T) + I(r) + G
2. 写出LM方程：M/P = L(Y, r)
3. 从两个方程中消去r
4. 得到Y与P的关系 → 就是AD函数

### 题型2：分析政策效果
**解题步骤**：
1. 判断哪条曲线移动（IS、LM还是AS？）
2. 判断移动方向（左移还是右移？）
3. 画图分析：新均衡点的Y和P变化
4. 区分短期效应和长期效应

### 题型3：滞胀分析
**关键点**：
- 滞胀 = 高通胀 + 低增长
- 原因：AS曲线左移（不利供给冲击）
- 政策两难：刺激需求会加剧通胀，抑制通胀会加深衰退

---

## 总结

IS-AS模型告诉我们：

1. **经济有两个市场**：产品市场（IS）和货币市场（LM → AD）
2. **价格是关键桥梁**：连接短期和长期
3. **政策有时间维度**：短期有效，长期只变价格
4. **供给很重要**：供给冲击会带来"滞胀"难题

**记住**：经济学模型不是精确的预测工具，而是帮助思考的"思维框架"。
