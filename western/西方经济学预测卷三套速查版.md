## 一、第一套速查

### 1. 选择题

1. 需求右移，均衡价格上升、均衡数量增加：`B`
2. 货币政策三大一般性工具不包括信贷配给：`D`
3. 购买力平价下，高通胀国货币趋于贬值：`B`
4. 税负转嫁正确说法是 `①②③`：`A`
5. 商业银行最基本功能是信用中介：`A`
6. 马克思主义经济学逻辑起点是社会人：`B`
7. WTO 属于国际经济组织：`C`
8. 新古典增长模型稳态时人均资本增长率为零：`D`

### 2. 名词解释

优先会写：

- 帕累托最优状态
- 财政赤字排挤效应
- 汇率制度
- 市场失灵

最稳写法：

- 第一句先下定义
- 第二句写核心特征
- 第三句写分类、机制或政策含义

### 3. 简答题

这一套的西经简答核心是：

1. 凯恩斯流动偏好理论及三大动机
2. 渐进式改革的特点及成功原因

直接记关键词顺序：

- 流动偏好：`交易动机 -> 预防动机 -> 投机动机 -> L=L1(Y)+L2(r)`
- 渐进式改革：`利用既有组织资源 -> 增量改革 -> 试点推广 -> 改革发展稳定`

### 4. 论述题

西经方向最像的是收入分配制度。

关键词顺序：

- 按劳分配为主体
- 多种分配方式并存
- 按要素分配
- 初次分配重效率
- 再分配重公平
- 效率与公平统一

### 5. 计算题

题型：`IS-LM + 财政扩张 + 挤出效应`

必须会写：

$$
Y=C+I+G
$$

$$
L=\frac{M}{P}
$$

结果速记：

- `IS: Y = 1320 - 80r`
- `LM: Y = 800 + 80r`
- 初始均衡：`r = 3.25, Y = 1060`
- `G` 从 `50` 增到 `90` 后：`r = 4.25, Y = 1140`
- 政府购买乘数：`2`
- 被挤出的私人投资：`20`

这题考点：

- 会不会列 `IS`
- 会不会列 `LM`
- 会不会联立
- 会不会解释挤出效应

## 二、第二套速查

### 1. 选择题

1. 边际产量大于平均产量，平均产量递增：`A`
2. 贷款不是商业银行负债项目：`B`
3. 本国利率高于外国利率，远期汇率贴水：`B`
4. 拉弗曲线反映税率与税收收入关系：`B`
5. 产权核心功能是约束对稀缺资源的竞争：`B`
6. 货币供给外生性是中央银行独立控制货币量：`B`
7. 按教材口径，经济全球化根本推动力是各国经济发展的客观要求：`B`
8. 基尼系数越接近 `1` 越不平等：`C`

### 2. 名词解释

优先会写：

- 边际技术替代率递减规律
- 通货膨胀目标制
- 贸易条件
- 企业治理结构

### 3. 简答题

这一套的西经简答核心是：

1. 弗里德曼货币需求理论及与凯恩斯的区别

关键词顺序：

- 永久收入
- 货币需求较稳定
- 利率作用较小
- 单一规则
- 与凯恩斯比较：决定因素 / 稳定性 / 政策主张

### 4. 论述题

题目是政府调节经济的必要性和手段，这类题和“市场失灵与政府干预”高度一致。

关键词顺序：

- 市场失灵
- 外部性
- 垄断
- 公共物品
- 信息不对称
- 财政政策
- 货币政策
- 行政与法制手段

### 5. 计算题

题型：`垄断厂商利润最大化 + 从量税 + 税负归宿`

必须会写：

$$
TR=P(Q)\cdot Q
$$

$$
MR=\frac{dTR}{dQ}
$$

$$
MR=MC
$$

结果速记：

- `MR = 100 - 4Q`
- `MC = 20 + 2Q`
- 税前最优：`Q = 40/3 = 13.33`
- 税前价格：`P = 220/3 = 73.33`
- 税前利润：`483.3`
- 征收单位税 `10` 后，新 `MC = 30 + 2Q`
- 税后最优：`Q = 70/6 = 11.67`
- 税后价格：`P = 230/3 = 76.67`
- 税负分担：消费者约承担 `1/3`，生产者约承担 `2/3`

这题最容易错的地方：

- 利润计算
- 从量税加在 `MC` 上而不是直接改需求
- 税负分担要看价格变化，不是默认一人一半

## 三、第三套速查

### 1. 选择题

1. 边际产量等于零时，总产量达到最大值：`A`
2. 中央银行负债包括通货、准备金和政府存款：`B`
3. 比较利益理论的基础是相对成本差异：`B`
4. 个人所得税属于直接税：`C`
5. 我国社会保障制度核心是社会保险：`B`
6. 货币供给增加，`LM` 右移且利率下降：`B`
7. 华盛顿共识核心是资本与市场全面开放：`B`
8. `Ed < 1` 时涨价可增加总收益：`B`

### 2. 名词解释

优先会写：

- 科斯定理
- 公开市场业务
- 两缺口模型
- 规模经济

### 3. 简答题

这一套的西经简答核心是：

1. 财政支出规模增长的理论解释

关键词顺序：

- 瓦格纳法则
- 梯度渐进增长论
- 经济发展阶段论
- 官僚行为增长论

### 4. 论述题

这套论述更偏社会主义经济学，但和西经也有交叉点：

- 国企改革
- 现代企业制度
- 公司治理结构
- 自然垄断行业分类改革

如果只按西经角度吸收，重点看：

- 公司治理结构
- 产权改革
- 自然垄断与规制

### 5. 计算题

题型：`供求均衡 + 点弹性 + 最高限价 + 补贴归宿`

必须会写：

$$
Q_d=Q_s
$$

$$
E_d=\frac{dQ}{dP}\cdot\frac{P}{Q}
$$

结果速记：

- 原均衡：`P = 35, Q = 125`
- `P = 20` 时需求弹性：`Ed = -0.5`
- 结论：`|Ed| = 0.5 < 1`，缺乏弹性
- 最高限价 `P = 25` 时短缺：`100`
- 单位补贴 `5` 后新供给：`Qs' = -25 + 5P`
- 新均衡：`P = 32.5, Q = 137.5`
- 补贴分担：消费者每单位受益 `2.5`，生产者每单位受益 `2.5`

这题考点：

- 会不会解均衡
- 会不会算点弹性
- 会不会判断缺乏弹性
- 会不会处理限价与短缺
- 会不会分析补贴归宿
