# 西方经济学高频大题速背骨架

这份资料只做一件事：把西方经济学里最容易出大题、最容易混的部分，压成可以直接默写的骨架。

使用方法：

1. 先只看题目。
2. 先默写“关键词骨架”。
3. 再把关键词扩成 4 到 6 句。
4. 最后回章节补公式和图形。

记忆原则：

- 微观看`价格机制 -> 厂商决策 -> 市场效率`。
- 宏观看`国民收入 -> IS-LM -> 政策 -> AD-AS -> 增长通胀`。
- 先记结论，再记推导。

### 1. 需求定理与需求曲线为什么向右下方倾斜

适用题型：

- 为什么需求曲线向右下方倾斜
- 影响需求变动的主要因素

关键词骨架：

`替代效应`
`收入效应`
`价格与需求量反向变动`
`需求变动 vs 需求量变动`

记忆钩子：

`价格变，量沿线动；非价变，整条线平移。`

最短展开：

1. 在其他条件不变时，商品价格上升会引起需求量下降，价格下降会引起需求量上升。
2. 需求曲线向右下方倾斜，主要来自替代效应和收入效应共同作用。
3. 价格变化引起的是同一条需求曲线上的点移动。
4. 收入、相关商品价格、偏好和预期变化引起的是需求曲线整体移动。

### 2. 需求价格弹性的含义及其应用

适用题型：

- 什么是需求价格弹性
- 弹性与厂商销售收入的关系

关键词骨架：

`价格变动的反应程度`
`富有弹性`
`缺乏弹性`
`总收益`

记忆钩子：

`薄利能否多销，先看弹性大小。`

最短展开：

1. 需求价格弹性表示价格变动 1% 所引起的需求量变动百分比。
2. `|Ed|>1` 表示富有弹性，降价通常会增加总收益。
3. `|Ed|<1` 表示缺乏弹性，提价通常会增加总收益。
4. 弹性大小取决于替代品多少、支出比重、用途广狭和时间长短。

### 3. 边际效用递减规律与消费者均衡

适用题型：

- 什么是边际效用递减规律
- 如何实现消费者均衡

关键词骨架：

`总效用`
`边际效用递减`
`预算约束`
`等边际原则`

记忆钩子：

`钱花在最后一元最值的地方。`

最短展开：

1. 随着某商品消费量增加，其边际效用通常趋于递减。
2. 消费者在收入和价格约束下追求总效用最大化。
3. 均衡条件是各种商品最后一单位货币带来的边际效用相等。
4. 这说明消费者会在不同商品之间不断调整支出结构，直到无法再提高总效用。

### 4. 短期生产三阶段与边际报酬递减规律

适用题型：

- 边际报酬递减规律
- 总产量、平均产量和边际产量关系

关键词骨架：

`可变投入`
`边际产量`
`平均产量`
`合理生产区`

记忆钩子：

`先增效，后减速，再拖累。`

最短展开：

1. 在技术不变且至少一种要素固定时，连续增加可变要素，边际产量最终会递减。
2. 短期生产可分为边际产量递增、边际产量递减但为正、边际产量为负三个阶段。
3. 理性的生产者通常在第二阶段生产，因为此时总产量仍在增加且要素利用较合理。
4. `MP>AP` 时平均产量上升，`MP<AP` 时平均产量下降。

### 5. 完全竞争市场的短期均衡与长期均衡

适用题型：

- 完全竞争厂商均衡条件
- 完全竞争市场长期均衡特征

关键词骨架：

`P=MR=AR`
`MR=MC`
`超额利润吸引进入`
`长期零经济利润`

记忆钩子：

`短期看利润，长期看进入退出。`

最短展开：

1. 完全竞争厂商是价格接受者，单个厂商面临的需求曲线是水平线。
2. 厂商利润最大化条件是 `MR=MC`，而完全竞争下 `P=MR=AR`。
3. 短期内厂商可能获得超额利润或发生亏损。
4. 长期中，由于厂商进入和退出，市场会趋向 `P=MC=AC`，经济利润为零。

### 6. 垄断市场的形成、定价与福利损失

适用题型：

- 垄断厂商如何定价
- 垄断为什么导致福利损失

关键词骨架：

`进入壁垒`
`向下倾斜需求`
`MR<AR`
`MR=MC`
`无谓损失`

记忆钩子：

`垄断能抬价，但会缩量。`

最短展开：

1. 垄断形成通常源于规模经济、关键资源控制、专利或行政限制。
2. 垄断厂商面临向下倾斜的需求曲线，因此边际收益小于价格。
3. 利润最大化条件仍是 `MR=MC`，再由需求曲线决定价格。
4. 与完全竞争相比，垄断通常表现为价格更高、产量更低，并产生无谓损失。

### 7. 市场失灵的主要类型与政府干预

适用题型：

- 什么是市场失灵
- 政府为什么要干预市场

关键词骨架：

`垄断`
`外部性`
`公共物品`
`信息不对称`
`政府矫正`

记忆钩子：

`市场有效率，但不是万能。`

最短展开：

1. 市场机制通常能通过价格信号实现资源配置，但在某些情形下会失灵。
2. 典型市场失灵包括垄断、外部性、公共物品和信息不对称。
3. 这些问题会导致私人决策与社会最优不一致。
4. 政府可以通过反垄断、税收补贴、公共供给和监管等方式进行矫正。

### 8. IS-LM 模型及财政政策、货币政策效果

适用题型：

- 什么是 IS-LM 模型
- 财政政策和货币政策如何影响收入与利率

关键词骨架：

`产品市场均衡`
`货币市场均衡`
`IS`
`LM`
`政策传导`

记忆钩子：

`财政动 IS，货币动 LM。`

最短展开：

1. `IS` 曲线表示产品市场均衡条件下收入与利率的组合，`LM` 曲线表示货币市场均衡条件下收入与利率的组合。
2. 两条曲线交点决定短期均衡收入和利率。
3. 扩张性财政政策使 `IS` 右移，通常带来收入上升和利率上升。
4. 扩张性货币政策使 `LM` 右移，通常带来收入上升和利率下降。

### 9. 总需求与总供给模型及通货膨胀、失业

适用题型：

- 总需求与总供给模型
- 通货膨胀与失业的关系

关键词骨架：

`总需求`
`总供给`
`短期波动`
`需求拉动`
`成本推动`

记忆钩子：

`看总量波动，最终落到 AD-AS。`

最短展开：

1. 总需求反映社会对最终产品和劳务的总支出，总供给反映经济在不同价格水平下的供给能力。
2. `AD-AS` 模型用于说明价格总水平与总产出的共同决定。
3. 总需求过快扩张可能带来需求拉动型通货膨胀。
4. 成本上升可能推动总供给左移，从而形成成本推动型通货膨胀和产出下降并存。

### 10. 经济增长与经济发展的区别

适用题型：

- 什么是经济增长
- 增长与发展的区别和联系

关键词骨架：

`数量扩张`
`质量提升`
`技术进步`
`制度因素`
`可持续`

记忆钩子：

`增长看量，发展看质量。`

最短展开：

1. 经济增长主要表现为一国总产出或人均产出的持续增加。
2. 经济发展不仅包括数量增长，还包括结构优化、制度进步和福利改善。
3. 长期增长来源于资本积累、劳动投入和技术进步。
4. 现代经济学更强调高质量、可持续和包容性发展。
