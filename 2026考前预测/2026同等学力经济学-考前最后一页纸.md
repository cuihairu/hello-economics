## 一、名词解释速背（每题3分）

### 1. 成本推动型通货膨胀
●从供给或成本方面分析通胀形成机理的假说。
●（1）工资推进型：工会强大→工资高于竞争水平→企业提价→工资-价格螺旋
●（2）利润推进型：垄断企业操纵价格→获取垄断利润→推高整体物价

### 2. 流动偏好陷阱
●利率极低时，人们预期证券价格不再上升，偏好持有货币。
●货币需求趋于无穷大（凯恩斯陷阱）。
●扩张性货币政策无效，财政政策更有效。

### 3. 自然垄断
●规模经济显著，平均成本持续下降，一家供给比多家供给更有效率。
●固定成本高、规模报酬递增、网络效应。
●常见于电力、燃气、铁路等公用事业。

### 4. 货币供给内生性
●货币供应量由经济体系内部多主体共同决定，央行不能完全独立控制。
●商业银行信贷、财政收支、国际收支、微观主体货币需求都会影响货币供给。

### 5. 总供给曲线
●表示价格水平与总产出关系的曲线。
●短期向右上方倾斜（成本调整慢），长期垂直（由资源技术决定）。

### 6. 价格歧视
●同一商品向不同消费者收取不同价格。
●一级（完全）、二级（数量）、三级（市场）。
●条件：垄断力、市场可区分、不能转卖。

### 7. 交易成本
●搜寻成本、谈判成本、签约成本、监督成本。
●影响市场效率和制度选择。

### 8. 基尼系数
●衡量收入分配不平等程度的指标。
●0-1之间，越接近1越不平等。

## 二、简答题标准答案骨架（每题8分）

### 题型1：XX的成因及治理（模板）

**答案结构：**
●定义开头（1分）
●成因（3-4分）：分2-3点，每点展开
●治理（3-4分）：分2-3点，每点展开

**示例：成本推动型通胀**
●定义：从供给/成本方面分析的通胀假说
●成因：
  （1）工资推进：工会→工资↑→价格↑→螺旋（2分）
  （2）利润推进：垄断→操纵价格→成本↑（2分）
●治理：
  （1）收入政策：工资-物价指导线、管制工资（2分）
  （2）反垄断：限制垄断高价（1分）
  （3）改善供给：提高生产率（1分）

---

### 题型2：XX的含义及影响（模板）

**答案结构：**
●定义（1-2分）
●分类/类型（2-3分）
●影响/作用（3-4分）
○小结（1分）

**示例：汇率变动影响**
●本币贬值：
  （1）贸易：出口价格↓→出口↑，进口价格↑→进口↓（2分）
  （2）国内：促进出口产业、输入通胀、外债负担↑（2分）
●本币升值：
  （1）有利：进口成本↓、抑制通胀、促进对外投资（2分）
  （2）不利：出口压力↑、贸易逆差、储备缩水（2分）

---

### 题型3：XX的机制/传导（模板）

**答案结构：**
●定义（1-2分）
●机制/渠道（5-6分）：分3-4条渠道
●影响因素（1-2分）

**示例：货币政策传导机制**
●定义：央行工具→中介目标→最终目标的途径（1分）
●渠道：
  （1）利率：M↑→r↓→I、C↑→Y↑（2分）
  （2）信贷：M↑→银行可贷资金↑→融资易→I↑（1.5分）
  （3）资产价格：M↑→r↓→资产价格↑→Q↑→I↑（1.5分）
  （4）汇率：M↑→r↓→资本外流→本币贬值→NX↑（1分）
●因素：微观主体敏感度、金融市场发达程度、开放程度（1分）

---

### 题型4：XX模型/曲线分析（模板）

**答案结构：**
●模型/曲线定义（1-2分）
●变动分析（4-5分）：分情况说明
●结论/政策含义（2-3分）

**示例：IS-LM政策影响**
●财政政策影响IS：
  扩张财政（G↑或T↓）→IS右移→Y↑r↑（2分）
  紧缩财政（G↓或T↑）→IS左移→Y↓r↓（1分）
●货币政策影响LM：
  扩张货币（M↑）→LM右移→Y↑r↓（2分）
  紧缩货币（M↓）→LM左移→Y↓r↑（1分）
●政策搭配：根据经济状况选择合适组合（2分）

## 四、必背公式

| 公式 | 含义 | 记忆要点 |
|------|------|----------|
| $E_d = \frac{\Delta Q/Q}{\Delta P/P}$ | 需求价格弹性 | $\|E_d\|>1$降价增收 |
| $k = \frac{1}{1-MPC}$ | 投资乘数 | MPC越大乘数越大 |
| $m = \frac{1+c}{r+e+c}$ | 货币乘数 | r越小乘数越大 |
| $G = \frac{s}{v}$ | 哈罗德-多马 | s↑G↑，v↑G↓ |
| $r = i - \pi$ | 实际利率 | 名义利率-通胀率 |
| $e = \frac{P_A}{P_B}$ | 购买力平价 | 两国物价之比 |
| $MRS_{xy} = \frac{P_x}{P_y}$ | 消费者均衡 | 边际替代率=价格比 |
| $MR = MC$ | 利润最大化 | 垄断厂商均衡条件 |

## 五、易混淆点辨析

| 概念 | 核心区别 |
|------|----------|
| 名义GDP vs 实际GDP | 是否扣除物价变动 |
| 名义利率 vs 实际利率 | 是否扣除通胀：$r=i-\pi$ |
| 需求拉动 vs 成本推动 | 需求过剩 vs 成本上升 |
| 内生性 vs 外生性 | 内部决定 vs 央行控制 |
| 固定汇率 vs 浮动汇率 | 央行干预 vs 市场决定 |
| 经济增长 vs 经济发展 | 数量 vs 质量+结构 |
| 菲利普斯曲线（短期） | 通胀与失业替代（负相关） |
| 菲利普斯曲线（长期） | 垂直，无替代关系 |
| 一级价格歧视 | 完全歧视，消费者剩余全部被厂商占有 |
| 三级价格歧视 | 按市场分割定价 |
