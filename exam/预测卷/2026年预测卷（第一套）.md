## 二、名词解释（每小题 3 分，共 12 分）

### 1. 帕累托最优状态

帕累托最优状态是指资源分配的一种理想状态：没有人可以在不使他人境况变差的条件下改善自身境况。此时资源配置达到了经济效率，任何重新配置都会至少损害一个人的利益。

### 2. 财政赤字排挤效应

财政赤字排挤效应是指政府通过增加支出或减税实施扩张性财政政策时，导致利率上升，从而挤出了私人投资。分为完全挤出效应、部分排挤效应和零排挤效应。

### 3. 汇率制度

汇率制度是指一个国家或经济体对于确定、维持、调整与管理汇率的原则、依据、方法和机构等所作出的系统规定。主要分为固定汇率制和浮动汇率制两大类。

### 4. 市场失灵

市场失灵是指市场机制不能有效地配置资源。狭义指完全竞争市场条件不满足导致的效率缺失；广义还包括市场机制运行中出现经济波动和收入分配不公平等现象。

## 三、简答题（每小题 8 分，共 32 分）

### 1. 简述凯恩斯的流动偏好理论及其三大动机。

凯恩斯认为，人们持有货币的偏好（即流动性偏好）决定了货币需求。人们之所以偏好持有货币，是出于以下三种动机：

1. **交易动机**：为应付日常交易需要而持有货币。交易性货币需求与收入水平正相关。
2. **谨慎动机**（预防动机）：为应付意外支出而持有货币。同样与收入正相关。
3. **投机动机**：为在有利时机购买有价证券获利而持有货币。投机性货币需求与利率呈反方向变动——利率越高，投机性货币需求越少。

因此，凯恩斯的货币需求函数可表示为：L = L₁(Y) + L₂(r)，即货币需求由收入和利率共同决定。

### 2. 简述幼稚产业的三个判定标准。

幼稚产业是指通过政策保护一段时间后，能够掌握技术、形成比较优势并最终在自由贸易下获利的产业。

1. **穆勒标准（产业自理原则）**：某种产业由于技术不足、成本高于国际市场而无法竞争，但在保护下能够在自由贸易条件下获利、自我发展，即为幼稚产业。
2. **巴斯塔布尔标准（成本收益原则）**：保护幼稚产业的社会成本不应超过该产业将来利润的现值总和。
3. **肯普标准（外部性原则）**：如果某产业的技术可为其他产业获得，即使本产业利润无法补偿投资成本，国家也应进行保护。

### 3. 简述国家预算的基本原则。

国家预算原则是制定政府财政收支计划的指导思想，主要包括：

1. **公开性**：预算及其执行情况必须公之于众，接受民众监督。
2. **可靠性**：收支数字必须依据充分，不得假定或任意编造。
3. **完整性**：一切财政收支都要列入预算，不得另列预算外账目。
4. **统一性**：各级预算共同组成统一的国家预算。
5. **年度性**：预算的编制和实现要有时间限定，通常为一年。

### 4. 简述我国渐进式改革的特点及取得成功的原因。

**渐进式改革的特点**：
1. **利用已有组织资源**推进市场取向的改革，而非"推倒重来"。
2. **增量改革**：在不触动既得利益格局前提下，在边际上推进改革。
3. **先试点后推广**：先在局部取得经验，再全局推广。

**成功的原因**：
1. 把社会主义基本经济制度与市场经济结合起来。
2. 以"三个有利于"标准判断改革成效。
3. 处理好改革、发展与稳定的关系。
4. 随着经济体制改革深入，适时推进政治体制改革。

## 四、论述与计算题（每小题 20 分，共 40 分）

### 1. 试述我国社会主义市场经济条件下收入分配制度的主要内容。

**（1）按劳分配为主体**

按劳分配是社会主义经济中个人消费品分配的基本原则，指社会总产品在作必要扣除后，按劳动者提供的有效劳动量分配个人消费品。在社会主义市场经济条件下，按劳分配需要通过市场交易关系才能实现。

**（2）多种分配方式并存**

以公有制为主、多种所有制共同发展的所有制结构，决定了分配制度的多元化：
- 公有制经济中主要通行劳动标准，实行按劳分配。
- 非公有制经济中主要通行所有权标准，实行按生产要素分配。

**（3）劳动标准与所有权标准相结合**

两种标准的结合使得多种分配方式相互渗透、相互影响，形成适合社会主义市场经济的收入分配结构。劳动、资本、技术、管理等生产要素按贡献参与分配。

**（4）兼顾效率与公平**

- 初次分配注重效率，发挥市场机制的作用。
- 再分配注重公平，政府通过税收、社会保障、转移支付等手段调节收入差距。
- 既反对平均主义，又防止收入差距悬殊。

### 2. IS-LM 模型计算题

已知消费函数 C = 80 + 0.75Y，投资函数 I = 200 − 20r，政府购买 G = 50，货币需求函数 L = 0.5Y − 40r，名义货币供给 M = 400，价格水平 P = 1。

**(1) 求 IS 曲线和 LM 曲线。**

由 Y = C + I + G = 80 + 0.75Y + 200 − 20r + 50，化简得 **IS 曲线：Y = 1320 − 80r**

由 L = M/P，即 0.5Y − 40r = 400，化简得 **LM 曲线：Y = 800 + 80r**

**(2) 求均衡国民收入和利率。**

联立 IS 和 LM：1320 − 80r = 800 + 80r，解得 **r = 3.25，Y = 1060**

**(3) 若政府购买 G 从 50 增加到 90，求新的均衡国民收入和利率，并计算政府购买乘数。**

新 IS 曲线：Y = 80 + 0.75Y + 200 − 20r + 90，化简得 Y = 1480 − 80r

联立新 IS 和 LM：1480 − 80r = 800 + 80r，解得 **r = 4.25，Y = 1140**

政府购买乘数 = ΔY / ΔG = (1140 − 1060) / (90 − 50) = 80 / 40 = **2**

**(4) 解释挤出效应。**

政府购买增加后，利率从 3.25% 上升到 4.25%，私人投资减少。ΔI = −20 × (4.25 − 3.25) = −20。即政府支出的增加挤出了 20 单位私人投资，这就是挤出效应。
