# 经济学知识点主文档

本站按课程组织:西方经济学、货币银行学、财政学、国际经济学四门课,加数学基础一组。这一页收拢五件事:哪门课以哪本通行教材为框架、名著与理论的时间坐标、官方文档与数据源、应用场景与学习路径、本站的口径约定。底稿是[参考书目](reference/参考书目.md)、[名著篇](books.md)与八个官方站点的实取记录(2026-10-10),出处不足处就地标注,不硬写。

## 一、课程框架与教材

1. **西方经济学以高鸿业的十五章为骨架。** 高鸿业《西方经济学》(第八版,微观/宏观分册,中国人民大学出版社)是章节框架的主要来源——从需求与供给到宏观经济学的意见分歧共十五章,即该体系。曼昆《经济学原理》是同一体系的另一套讲法,案例更丰富;梁小民《西方经济学导论》(第四版)补入门视角。见 [参考书目](reference/参考书目.md) 西方经济学条。

2. **货币银行学走曹龙骐《金融学》的框架。** 第六版,货币供求、利率、金融体系与政策各章以此为准;米什金《货币金融学》补货币需求与货币传导机制的实证视角。

3. **财政学的结构来源是陈共《财政学》。** 第十版,财政职能、支出、税收、国债、预算与赤字各章的组织沿用这本书。

4. **国际经济学的主流框架出自克鲁格曼。** 克鲁格曼、奥伯斯法尔德《国际经济学》覆盖贸易理论与开放宏观;国际收支与汇率章节的国内教材表述由高鸿业《西方经济学》宏观部分补足。

5. **社会主义经济理论一组两本书。** 卫兴华、张宇《社会主义经济理论》(高等教育出版社)是导论到政府调节各章的通行框架;吴敬琏《当代中国经济改革》提供制度变迁与改革史的经验叙述。

6. **数学基础对应国内通用教材的章节划分。** 同济大学《高等数学》是极限、微分、积分的标准讲法;线性代数与概率统计部分对应同类通用教材(如同济《线性代数》、盛骤《概率论与数理统计》)。具体版本以站内章节的实际引用为准。

7. **经济思想的史实参照有两条线。** 亨利·威廉·斯皮格尔《经济思想的成长》供时间线与名人篇的史实;马克·布劳格《经济理论的回顾》供理论谱系与批评性评述。原典级著作(亚当·斯密《国富论》1776、马歇尔《经济学原理》1890、凯恩斯《就业、利息和货币通论》1936、弗里德曼与施瓦茨《美国货币史》1963、哈耶克《知识在社会中的运用》1945、科斯《社会成本问题》1960)在涉及处见各章引注。

## 二、名著篇坐标

8. **十三本代表作按出版年份排开,每本对应一次提问方式的转向。** 从《国富论》(1776)划出学科边界,到《通论》(1936)在大萧条中翻转政策方向,再到《21 世纪资本论》(2013)让不平等重回议程中心。完整书单与封面见[名著篇](books.md),作者名在站内可跳转到[人物篇](people.md)词条。

## 三、官方文档与数据源

9. **FRED 是数据新闻的时间序列底座。** 圣路易斯联储运营,1991 年起提供全球时间序列;图表、Excel 插件、API 与课堂资源齐全,ALFRED 提供历史时点(vintage)数据。新闻里的 CPI、失业率、利率图多半出自这里。来源:[FRED 首页](https://fred.stlouisfed.org/)(2026-10-10 WebFetch 实取;本机 curl 连接层失败,双通道)。

10. **NBER 工作论文是追踪前沿的入口。** 非营利研究机构,19 个项目组;工作论文配通俗摘要(The Digest),Business Cycle Dating 委员会给美国衰退定官方纪年——峰月是扩张的最后一个月、谷月是衰退的最后一个月,判据是深度、扩散、持续性三项月度指标,且故意回溯、等数据稳定再宣布。来源:[NBER 首页](https://www.nber.org/)、[Business Cycle Dating](https://www.nber.org/research/business-cycle-dating)(2026-10-10 实取)。

11. **BEA 是美国 GDP 的官方发布方。** 商务部下属统计机构,GDP、个人收入与支出、国际贸易、区域数据按主题、地区、账户发布;交互数据表(iTable)与 Learning Center 对自学者友好。来源:[BEA 首页](https://www.bea.gov/)(2026-10-10 实取)。

12. **世界银行 Open Data 做跨国比较。** 免费开放全球发展数据,WDI 按经济体或指标浏览,DataBank 可视化,地图按收入分组着色;2026 年起并入 Data360 平台。来源:[World Bank Open Data](https://data.worldbank.org/)(2026-10-10 实取)。

13. **国家统计局是中国宏观数据的官方出口。** 月度、季度、年度、普查、国际、部门数据与《中国统计年鉴》在线可查,PMI、工业生产者出厂价格等发布在首页。来源:[国家统计局](https://www.stats.gov.cn/)(2026-10-10 实取;首轮本机 curl 连接层失败、WebFetch 取正文,同日复测 curl 200)。

14. **人民银行是中国货币政策的一手出处。** 官网按货币政策、调查统计、金融稳定等栏目组织,货币政策委员会季度例会公告、货币政策工具调整通知与各类报告在此首发,站内还备术语表与金融知识栏目。读[货币政策](monetary/货币政策.md)章时,工具箱的每一步扩容都能回到这里对原文。来源:[人民银行官网](https://www.pbc.gov.cn/)(2026-10-10 本机 curl 实取;首轮 302,复测 200)。

15. **欧洲央行是欧元区货币政策的一手出处。** 官网按货币政策与市场、价格稳定目标(2%)、公开市场操作、资产购买计划等栏目组织,最新货币政策新闻发布会(2026-09-10)与各类报告在此首发;读[货币政策](monetary/货币政策.md)章时,工具箱与传导机制的每一步都能回到这里对原文。来源:[欧洲央行官网](https://www.ecb.europa.eu/)(2026-10-10 本机 curl 实取:首页 302 跳转英文页 200;此前测得时通时断,本轮复测可达)。

16. **诺贝尔经济学奖官网是人物篇的年度校验点。** 1968 年由瑞典央行设立,每年十月公布得主;官网有得主故事与科普文章,可对照[人物篇](people.md)的条目与年份。来源:[诺贝尔奖官网经济学奖页](https://www.nobelprize.org/prizes/economic-sciences/)(2026-10-10 本机 curl 实取;WebFetch 403 反爬,双通道)。

## 四、应用场景与学习路径

16. **读懂数据新闻先找发布方。** CPI 看 BLS 或统计局、GDP 看 BEA 或统计局、利率看 FRED 与人民银行;读公报先分清同比与环比、基期与口径,同比、环比、基期三条见[术语篇](glossary.md),再看图。本站[通货膨胀与通货紧缩](monetary/通货膨胀与通货紧缩.md)章与[宏观经济活动与宏观经济学](western/宏观经济活动与宏观经济学.md)章按这个读法组织。来源:本批实取,见三节第 9、11、13、14 条。

17. **追踪前沿走 NBER 加诺奖两条线。** 工作论文配 New This Week 邮件推送,通俗摘要 The Digest 免费可读;每年十月诺奖公布是理论影响力的年度刻度。来源:三节第 10、16 条(2026-10-10 实取)。

18. **原典与史料去 FRASER。** 圣路易斯联储的数字化经济史档案,收录美联储公报、总统经济报告等历史文献扫描件;本站[名著篇](books.md)十三本原典的出处可在此对读。来源:FRED 首页对 FRASER 的转述(2026-10-10 实取);FRASER 本站双通道均未通,内容细节来源未考。

19. **自学路径:时间线→课程→名著→人物。** 先在[理论时间线](timeline.md)读问题怎么被回答,再进课程章(每课 Readme 有「理论的诞生与验证」),然后按[名著篇](books.md)年份读原典,最后在[人物篇](people.md)看影响网络。来源:本站结构(2026-10-10 走查)。

## 五、口径与坑

20. **时间线的年份取「出现年」,不取「接受年」。** 科斯 1960 年的《社会成本问题》当年几无人引用,到 1970 年代经斯蒂格勒的命名与推广才成为法律经济学的地基;理性预期 1961 年由穆思提出,直到 1976 年卢卡斯批判之后才真正改写宏观模型。「共识形成」的时刻通常滞后十五到二十年,要画是另一条线。此口径在[理论时间线](timeline.md)页内注明。

21. **曼昆与高鸿业是同一体系的两种讲法,不是两套对立理论。** 正文以高鸿业框架组织,曼昆作案例补充;比较两者时按「讲法差异」写,不按「理论分歧」写。

22. **本站不堆背诵要点,只回答三个问题。** 为什么出现(它当时要解决什么问题)、如何发展(谁修正了它,留下什么新问题)、如何被验证(现实数据与后来的研究站在哪一边)——章节的「理论的诞生与验证」一节按这个口径写,公式回到它诞生的处境里。

23. **经济数据会修订,引用要带时点意识。** BEA 的 GDP 初值会随数据完善修订,NBER 判峰谷故意等数据稳定再宣布;FRED 的 ALFRED 专门存历史时点数据。引用数字时注明取数日期与版本。来源:三节第 9、10、11 条(2026-10-10 实取)。

24. **官方站点反爬各不相同,判定可达性要双通道,且通道本身会时通时断。** 首批实测:BLS、IMF 对 curl 返回 403,FRED、FRASER 本机连接层失败但 WebFetch 可取,诺奖官网相反(curl 200、WebFetch 403)。同日复测:FRED、FRASER 仍 000,ECB 302(跳英文页 200),IMF、OECD 403(反爬),BLS 由 403 转 000;这一轮 WebFetch 对全部域名报「无法验证域名安全性」,属工具侧网络限制而非站点不可达。同一站点不同时点结果会变(统计局失败转 200、人民银行 302 转 200 同理),单一通道的失败不作数。来源:本批实测(2026-10-10 两轮)。

25. **查无实据与未开展项。** 官方文档与应用场景两节已于 2026-10-10 补入(三、四节);FRASER 内容细节、IMF、OECD、BLS 正文未实取,不设条目;RePEc 系研究者自治档案而非官方发布方,不入「官方文档」节(2026-10-10 拍板)。ECB 原以「时通时断」不入册,同日复测可达(302→200),依据不成立,补入三节第 15 条(2026-10-10 拍板修订);其余条目均有出处。
