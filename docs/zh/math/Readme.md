# 经济学里的数学工具：我的整理笔记

我整理这部分时没有把数学单独拆成一门学科，而是围绕一个实际问题：
经济学里常见的模型、图形、推导和实证分析，到底分别依赖哪些数学工具。

这组数学工具与经济学专题的对应关系、名著坐标与官方数据源，收拢在 [知识点主文档](/zh/knowledge)。

## 我整理这部分时遇到的几类问题

- **我看到经济学公式时，连符号都读不懂怎么办**
  集合、逻辑、函数、数列和求和是符号阅读的起点。
- **我知道图像怎么画，但不知道为什么「边际」「最优」「均衡」能这样分析**
  常用到微分、积分、矩阵和特征值。
- **我知道理论图形，但看不懂数据、回归和经验研究**
  常用到概率论和统计学。
- **我知道静态均衡，但看不懂动态调整过程**
  常用到数列极限、微分方程、特征值与特征向量。

## 这些工具在经济学分析中的用处

**西方经济学**
- 需求、供给、效用、成本、厂商理论：主要依赖微分学、积分学。
- 一般均衡、福利分析：需要矩阵、线性空间、最优化基础。
- 宏观增长与动态分析：需要数列极限、微分方程、特征值。

**国际经济学**
- 贸易模型与要素流动：常用集合、函数、比较静态分析。
- 汇率与开放经济宏观：会用到微分、矩阵、动态稳定性分析。

**财政学**
- 税负分析、超额负担、最优税收：常用微分、积分和统计。
- 财政乘数、预算约束：常用求和、数列和联立方程。

**货币银行学**
- 利率、货币供求、资产组合选择：需要微分、概率、统计。
- 金融市场和动态调整：需要矩阵、特征值、微分方程。

**计量与实证分析**
- 概率论和统计学是核心。
- 矩阵、线性空间和特征值是回归、最小二乘、PCA 等方法的基础。

## 我自己容易踩的几个坑

- 我整理公式时会同时记下它在经济学里回答什么问题，而不只留公式本身。
- 图形直觉不等于证明；不少结论还依赖极限、导数或矩阵结构。
- 能算题和会建模是两件事；关键还在于判断为什么要用这个工具。
