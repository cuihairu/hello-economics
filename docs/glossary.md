# 术语篇

同一门学科里，「贴水」在汇率和利率里含义不同，「弹性」散落在供求、收入、国际收支各处。这里把各门课程的核心术语集中到一个入口：统一释义、标注它出现的课程与章节，点开可以回到原文。支持检索，也可以当作目录逐课程浏览。

词条详情中的「出处」链接指向经实测的权威来源（多为维基百科对应词条，逐条可用性验证）；查无权威出处的词条暂不出链接（待核），可在 `scripts/glossary-cites.json` 增补后经 `pnpm glossary` 重生成。
