# Glossary

Within a single discipline, "discount" means something different in exchange rates and in interest rates, and "elasticity" is scattered across supply and demand, income and the balance of payments. I have gathered the terms common to each topic in one place: a single definition for each, with a note of where it appears, and clicking through returns you to the original text. Search is supported, and browsing by topic as well.

The "source" link in an entry's details points to an authoritative reference that has been checked individually (mostly the corresponding Wikipedia article, each one verified for availability); an entry with no verifiable authoritative source carries no link for now (pending review), and can be supplemented in `scripts/glossary-cites.json` and regenerated with `pnpm glossary`.
