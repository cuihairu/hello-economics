# 基础数据

这一课不在讲理论，而在讲**理论落地时要用到的那套度量衡**：

**GDP、CPI、M2、财政赤字、经常账户顺差这些数是怎么被算出来的，口径里埋着哪些坑，以及去哪个官方来源能自己复核一遍。**

经济学的大部分争论最后都会落到一个数字上：通胀到底高不高、宏观税负重不重、货币是不是放水了、债务有多少。但同一个问题在不同口径下会有不同答案，而这些差别在教科书里通常被省略。这一课就是把省掉的那部分补上：先把指标的定义与编制方法说清楚，再指出常见的读错方式，最后给出可以自己动手核对的公开数据源。

## 一、为什么把数据单独列成一课

1. **指标不是事实本身，而是对事实的一种编码。** GDP 计入自购住房的虚拟租金、不计家务劳动；CPI 用固定篮子、PPI 用出厂价；M1 与 M2 的边界在各国、在不同年份都被重画过。看懂一段争论，往往要先看它用的是哪个编码。
2. **口径差异能造出相反结论。** 「中国 GDP 增速」有同比、环比折年率、两年平均三种讲法；「财政赤字」有一本账赤字、含专项债的口径、IMF 的广义政府债务三个层次；「失业率」有调查失业率和登记失业率两套制度。同一个季度，三种说法都不算错，得出的政策含义却完全不同。
3. **数据的可得性塑造了理论的形状。** 没有国民收入账户，凯恩斯的有效需求不足就只是一个说法；没有高频支付与价格数据，2021—2022 年的「通胀是暂时性的吗」之争连讨论的抓手都没有。经济学史上很多方法论的分歧，实质是「当时能观测到什么」的分歧。
4. **写论文、做笔记要能复现。** 引用一个数字，需要说清它出自哪个机构、哪份表、什么时点、是否季调、后来有没有被修订。这四项缺任何一项，别人就无法重现你的结论。

## 三、使用方式

- 读其它章节遇到指标口径不清时回来看对应一节：《货币供求理论》里的 M1/M2、《财政平衡与财政赤字》里的赤字率、《经济增长》里的全要素生产率，都在这里有编制说明。
- 任何一处数字都标注了来源与时点；官方数据会修订（美国 GDP 有三度估计、中国统计公报后有年鉴最终核实数），所以写文章时要注明「初步核算」还是「最终核实」。
- 本课只讲口径与方法，不预测数据。所有具体数字都是为了说明「差多少」而举的例，一律以官方最新公布为准。
