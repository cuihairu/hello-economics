# 参考书目

> 本站内容整理自公开教材与讲义笔记，各课程正文的章节结构与理论表述主要对应下列通行教材。
> 理论的历史脉络部分另见 [理论时间线](/timeline) 与各课程 Readme 的「理论的诞生与验证」。

## 西方经济学

- 高鸿业《西方经济学》（第八版，微观/宏观分册，中国人民大学出版社）——章节框架的主要来源：需求与供给到宏观经济学的意见分歧共十五章即该体系。
- 梁小民《西方经济学导论》（第四版）——入门视角的补充。
- 曼昆《经济学原理》——同一体系的另一套讲法，案例更丰富。

## 货币银行学

- 曹龙骐《金融学》（第六版）——货币供求、利率、金融体系与政策各章的通行框架。
- 米什金《货币金融学》——货币需求与货币传导机制的实证视角补充。

## 财政学

- 陈共《财政学》（第十版）——财政职能、支出、税收、国债、预算与赤字的结构来源。

## 国际经济学

- 克鲁格曼、奥伯斯法尔德《国际经济学》——贸易理论与开放宏观的主流框架。
- 高鸿业《西方经济学》（宏观部分）——国际收支与汇率章节的国内教材表述。

## 社会主义经济理论

- 卫兴华、张宇《社会主义经济理论》（高等教育出版社）——导论到政府调节各章的通行框架。
- 吴敬琏《当代中国经济改革》——制度变迁与改革史的经验叙述。

## 数学基础

- 同济大学《高等数学》——极限、微分、积分的标准讲法。
- 线性代数与概率统计部分对应国内通用教材（如同济《线性代数》、盛骤《概率论与数理统计》）的章节划分。

## 经济思想史与人物

- 亨利·威廉·斯皮格尔《经济思想的成长》——时间线与名人篇的史实参照。
- 马克·布劳格《经济理论的回顾》——理论谱系与批评性评述。
