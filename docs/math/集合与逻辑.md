# Sets and logic

> **The central question of this chapter**: economics starts by naming "consumers", "firms", "goods", "states" — if those words are not given clear boundaries, no symbol in the model refers to anything definite. Why is set theory and logic, the most apparently "mathematics-department" of the tools, in fact the foundation of every economic model? What is the logical difference between "holds for all goods" and "there is at least one exception"?

## The arc of this chapter

Set theory was born at the end of the nineteenth century out of the need to make analysis rigorous. Cantor (1845-1918), studying trigonometric series, was forced to handle "the totality of infinitely many points"; the series of papers he published from 1874 turned the set itself into an object of study — a whole of objects drawn off by a definite property, with a clear boundary. At the same time Boole (1815-1864) translated Aristotelian logic into algebra in *The Laws of Thought* (1854), and Frege and Russell went on to hand mathematical propositions themselves over to logic; the set-theoretic paradox Russell discovered in 1902 ("the set of all sets that do not contain themselves") exposed the cracks in naive set theory and led into the axiomatic rebuilding of the early twentieth century. The lesson for economics: **if the objects of study are not first pinned down as sets, every later function, equation and proof is left hanging in the air**.

Economics needs this language at scale only when general equilibrium theory matures. Walras (1834-1910) described the whole economy's supply and demand with simultaneous equations, but proving that "an equilibrium exists and is unique" first requires saying what a "configuration" is — a mapping from the set of consumers and the set of goods to bundles of goods. The existence proofs of Arrow (1921-2017) and Debreu (1921-2004) in 1954 rest throughout on set-theoretic objects: the commodity space, the preference relation, the set of states. Von Neumann (1903-1957) and Morgenstern (1902-1977) did the same in *Theory of Games and Economic Behavior* (1944): the set of players, the set of strategies, the payoff function — a complete description of a game is exactly those three set-theoretic ingredients. The Model Setup section of any micro paper today is writing what this chapter is about.

The route of the chapter: first set out the notation and operations of sets (subsets, union, intersection, complement), then use the Cartesian product to formalise "combinations of several objects" — functions and relations are both defined on it — and finally bring in propositional and predicate logic, so that economic claims like "if the price rises then demand falls", "this holds for all consumers", "there is an exception" gain an exact syntax.

## Core concepts

### Sets and elements

A set is a whole of objects sharing some particular property; each object is called an element of the set. Sets are usually written with capital letters, elements with lowercase ones. There are two ways to write them: by listing all the elements, as in $A = \lbrace 1, 2, 3 \rbrace$; or by describing the property, as in $B = \lbrace x \mid x \text{ is an integer greater than 0 and less than 5} \rbrace$. Two special sets deserve to be remembered separately: the empty set $\emptyset$ (with no elements at all) and the universal set $U$ (all objects in the range of discussion).

Why do this first? Because a good part of the confusion in economic argument comes from unclear boundaries on the objects: does "consumer" include the farm household that grows its own food; is a "good" distinguished by time and state (is an apple today the same good as an apple next year); is cloud computing a "good"? Once the domain is pinned down as a set, an argument over words becomes a testable proposition. The vertical bar in the descriptive notation reads "such that", and this "property in, set out" construction is the everyday act of economic modelling: $\lbrace x \mid x \text{ satisfies the budget constraint} \rbrace$ is the budget set.

### Subsets, unions, intersections, complements

If every element of set $A$ is an element of set $B$, then $A$ is a subset of $B$, written $A \subseteq B$; if they contain each other then $A = B$. The union $A \cup B$ collects the elements belonging to $A$ or to $B$ (as in $\lbrace 1,2 \rbrace \cup \lbrace 2,3 \rbrace = \lbrace 1,2,3 \rbrace$), the intersection $A \cap B$ collects the elements in common (as in $\lbrace 1,2 \rbrace \cap \lbrace 2,3 \rbrace = \lbrace 2 \rbrace$), and the complement $A'$ (or $\overline{A}$) collects those elements of the universal set that do not belong to $A$ (if $U = \lbrace 1,2,3,4 \rbrace$ and $A = \lbrace 1,2 \rbrace$, then $A' = \lbrace 3,4 \rbrace$).

Why give each of the three operations its own symbol? Because they correspond to the three basic moves of economic analysis: "or" (a good belongs to the set of necessities or to the set of luxuries), "and" (a policy must land in the intersection of the feasible set and the optimal set), "not" (what is the set of exceptions to the law of demand). There is one bridge running through all three — De Morgan's law: $\overline{A \cup B} = A' \cap B'$, the negation of "(A or B)" is "not A and not B". It reappears as a truth table in the logic section below, and it is the most-used simplification rule once a verbal argument has been turned into a symbolic one.

### The Cartesian product

The Cartesian product of two sets $A$ and $B$ is the set of all ordered pairs $(a, b)$ with $a \in A$ and $b \in B$, written $A \times B$. For example, with $A = \lbrace 1, 2 \rbrace$ and $B = \lbrace 3, 4 \rbrace$, $A \times B = \lbrace (1, 3), (1, 4), (2, 3), (2, 4) \rbrace$.

Why is this apparently unremarkable construction indispensable? Because **relations and functions are both defined on a Cartesian product** — the demand function is a mapping from the set of prices to the set of quantities, and the mapping itself is a subset of the Cartesian product (the subset in which every input corresponds to exactly one output). Many of the objects economics handles are essentially elements of a Cartesian product: a bundle of goods is a vector over the set of goods (a point in $\mathbb{R}^n_+$), a "state-contingent consumption plan" is a mapping from the set of states to the set of consumption levels, and an insurance contract is an ordered pair of "state — payout". After Arrow subdivided commodities by "time × state", market analysis under uncertainty collapses back into the deterministic frame — and the whole technical basis of that step is the Cartesian product.

### Propositions and logical connectives

A proposition is a statement that can be judged true or false ("today is Monday" is a proposition; "raising the price is bad" has no criterion for the verdict and is not a strict proposition). Logical connectives build compound propositions: "and" ($\wedge$), "or" ($\vee$), "not" ($\neg$). The truth value of a compound proposition is completely characterised by a truth table; that of $p \wedge q$ is:

| $p$ | $q$ | $p \wedge q$ |
|:---:|:---:|:---:|
| T | T | T |
| T | F | F |
| F | T | F |
| F | F | F |

Two logical formulas are logically equivalent if they take the same value under every combination of truth values (as $p \wedge q$ and $q \wedge p$ do).

Why a table for "and"? Because the "and" and "or" of everyday speech are ambiguous ("or" in English can be exclusive — coffee or tea, not both), while the truth table pins every connective down as an unambiguous rule of operation. The place economic argument most easily goes wrong is exactly in negating a compound condition: to overturn the law of demand, "if $P$ rises then $Q$ falls", one needs a single counterexample of the form "$P$ rises and $Q$ does not fall" — not a pile of vague objections — which is precisely the content of $\neg(p \rightarrow q) \equiv p \wedge \neg q$.

### Predicates and quantifiers

A predicate is a logical function expressing a relation or a property of objects: $S(x)$ can stand for "$x$ is a student". Quantifiers give the range: the universal quantifier $\forall$ (for all) and the existential quantifier $\exists$ (there exists at least one). "All people are students" is written $\forall x\, S(x)$; "there exists a student" as $\exists x\, S(x)$.

Why are quantifiers the point of failure in economic argument? Because the two laws most often confused differ in nothing but the quantifier: "for every consumer the demand curve slopes down" is a $\forall$ proposition, while the existence of a Giffen good shows it must be stated as "$\exists$ an exception"; "market failure exists" is an $\exists$ proposition, "every government intervention fails" is a $\forall$ proposition — the slippery slope of policy debate is often just an $\exists$ being quietly swapped for a $\forall$ (or the other way round). Quantifiers also carry an order: $\forall y \exists x$ and $\exists x \forall y$ are not equivalent ("everyone has a dedicated adviser" and "there is one adviser who serves everyone" are two entirely different institutional arrangements), which shows up immediately in the formalisation of public-goods supply and matching problems.

## Problems and analysis

### Why must an economic model define its sets of objects first?

Because all of a model's conclusions are valid only inside its domain. General equilibrium theory defines "an economy" as $\lbrace$ the set of consumers, the set of firms, the set of goods, preferences, endowments, technologies $\rbrace$ — set theory makes clear at a glance what is inside the model and what is outside, so the boundary of a conclusion's applicability is testable. The warning lesson is a statistical one: taking the unemployment rate of the set "registered urban workers" for the unemployment rate of the set "whole working-age population" is a whisker off at the level of the conclusion and a mile off at the level of policy — a set boundary is simply the strict version of a statistical definition.

### How exactly is "if the price rises then demand falls" stated?

It is an implication $P \rightarrow Q$ (the price rises, therefore the quantity demanded falls), and the only case where its truth value is false is "$P$ rises and $Q$ does not fall". Two disciplines follow at once: first, testing or overturning the law requires only looking for the structure of a counterexample; second, "the price rose and demand did not fall, but income changed meanwhile" is a leak in the *ceteris paribus* condition, not the implication being overturned — an implication holds only when its terms are defined over the same domain with the other variables fixed, which is why a careful statement of the law of demand spells out "other things being equal" in full. Once everyday argument is translated into propositional logic, the sources of error expose themselves.

## Derivations and worked examples

### Checking De Morgan's law by truth table

Verify $\neg(p \wedge q) \equiv \neg p \vee \neg q$:

| $p$ | $q$ | $p \wedge q$ | $\neg(p \wedge q)$ | $\neg p$ | $\neg q$ | $\neg p \vee \neg q$ |
|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| T | T | T | F | F | F | F |
| T | F | F | T | F | T | T |
| F | T | F | T | T | F | T |
| F | F | F | T | T | T | T |

The two columns agree on all four rows, so the formulas are logically equivalent. Its economic reading: "it is not the case that (the price rose and sales rose too)" is the same as "either the price did not rise, or sales did not rise" — negate a conjunction and you get a disjunction.

### Defining a "configuration" with a Cartesian product

Let the set of consumers be $I = \lbrace 1, \ldots, m \rbrace$, with $n$ kinds of goods. A **configuration** assigns each consumer a bundle: $x = (x_1, \ldots, x_m)$, where each $x_i \in \mathbb{R}^n_+$. In this chapter's language, a configuration is an element of the Cartesian product $(\mathbb{R}^n_+)^m$. Feasibility requires $\sum_{i=1}^{m} x_i \le \omega$ ($\omega$ being the total social endowment). "Pareto optimal configuration" now has a strict definition: a feasible configuration such that no other element can make some $i$ strictly better off without making anyone else worse off. Every theorem of welfare economics unfolds on this set-theoretic definition.

## Limits and what comes next

The boundary of this chapter's tools and its later evolution run along three lines. First, **the paradoxes of naive set theory and the move to axioms**: Russell's paradox shows that "any property can define a set" leads to contradiction; Zermelo and Fraenkel established the ZFC axioms in the early twentieth century to constrain how sets may be constructed — "defining clearly" itself needs discipline, and the lesson for a modeller is that a badly chosen property can return a paradox instead of an object. Second, **the internal limits of logic**: Gödel's incompleteness theorems of 1931 show that in any sufficiently strong, consistent formal system there are true propositions that cannot be proved inside it — mathematics has no "final formal language", and economic claims ultimately rest on empirical testing rather than on logical closure. Third, **what economics did afterwards**: the logic of perfect rationality was amended by Simon (1916-2001)'s bounded rationality (deciders do not run a complete inference over the whole set but search for a satisfactory solution), and the asymmetric-information models — Akerlof's 1970 market for lemons — show the set structure of "who knows what" inside the domain (the information set) becoming the object of modelling itself. The functions, equations and probabilities of the chapters that follow all stand on the object language of this chapter.
