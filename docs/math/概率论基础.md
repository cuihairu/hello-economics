# 概率论基础

> **本章核心问题**：未来不确定时，「选择」还讲得通吗？买保险、配资产、投项目，这些决策背后的数学是什么？为什么样本里的波动未必是事实——「随机」如何被驯化成可计算的量？

## 本章脉络

概率论出生在赌桌上。1654 年，德·梅雷骑士就「点数问题」（赌局中断时如何公平分注）写信问帕斯卡，帕斯卡与费马的通信催生了期望值概念——概率论的第一份系统文献是一组书信。此后两个世纪，雅各布·伯努利 (1655-1705) 的大数定律（1713 年遗作出版）第一次把「频率稳定于概率」变成定理，棣莫弗与拉普拉斯推进正态曲线，高斯 (1777-1855) 从误差分析中再次发现它。但「概率」究竟是什么，众说纷纭（频率？信念？物理倾向？）——1933 年，柯尔莫哥洛夫 (1903-1987) 用测度论给出公理化：概率是满足三条公理的函数，随机性从此成为可严格运算的数学对象。

经济学需要概率，是因为它的几乎所有决策问题都押在未知上。1738 年丹尼尔·伯努利 (1700-1782) 解圣彼得堡悖论（期望值无穷但没人肯玩）时提出「效用随财富递减、按期望效用评估」，埋下风险偏好的种子；1944 年冯·诺伊曼与摩根斯坦把它公理化为期望效用理论，1979 年卡尼曼 (1934-2024) 与特沃斯基 (1937-1996) 的前景理论再修正——三百年间，概率论与经济学互相塑造：期望、方差、条件期望（信息）、随机占优，每个概念都对应一类经济决策。统计学基础（下一章）则是概率论的返场：从数据反推概率模型的参数。

本章路线：概率的公理与样本空间；条件概率与独立性（信息的数学形态）；随机变量、分布、期望与方差；常用分布清单（伯努利到正态——为什么正态无处不在）；大数法则与中心极限定理（随机如何表现出规律）。

## 核心概念

### 概率空间与三条公理

**样本空间** $S$ 是所有可能结果的集合，**事件**是样本空间的子集，**概率** $P(A)$ 是事件发生可能性的度量，取值在 $[0,1]$。三条公理：非负性（$P(A) \geq 0$）、归一性（$P(S) = 1$）、可列可加性（事件两两互斥时 $P\left(\bigcup_{i=1}^{\infty} A_i\right) = \sum_{i=1}^{\infty} P(A_i)$）。最常见的两事件版本：$P(A \cup B) = P(A) + P(B)$（$A$、$B$ 互斥）。

为什么要公理而不给定义？因为「概率是什么」的哲学之争（频率派与贝叶斯派至今未决）不妨碍「概率如何运算」的唯一性——柯尔莫哥洛夫的方案正是绕开本体论、直接立运算规则。经济建模的收益：违约、景气、政策通过与否，只要能指派满足三公理的数字，期望效用、风险溢价、期权定价的全部机器立即上线。注意「互斥才可加」：现实中「政策 A 的收益」与「政策 B 的收益」若不互斥（同时发生），加总前须扣除交集——概率的减法 $P(A \cup B) = P(A) + P(B) - P(A \cap B)$ 正是把「重叠被重复计入」修回来的那一步。

### 条件概率与独立性

条件概率是在 $B$ 已发生的前提下 $A$ 发生的概率：

$$P(A|B) = \frac{P(A \cap B)}{P(B)} \quad (P(B) > 0)$$

独立性：$P(A \cap B) = P(A)P(B)$，等价于 $P(A|B) = P(A)$——知道 $B$ 发生不改变 $A$ 的可能性。

为什么条件概率是「信息」的数学形态？因为拿到信息 = 缩小样本空间：从 $S$ 缩到 $B$，所有概率重新计算。金融里的贝叶斯更新（财报公布后资产价格跳变）、信号提取（卢卡斯货币错觉模型里工人分不清总量冲击与相对价格冲击，用的正是条件期望 $E(X|信息)$）、信贷审批（已知收入条件下违约概率的变化），全是条件概率的营业现场。独立性的反面教训更重要：**误把相关当独立是风险模型的经典死法**——2008 年金融危机中次贷违约相关性被系统性低估，copula 模型假设的独立性在房价普跌时瓦解，这是本章公理与金融现实之间最惨烈的一课。

### 随机变量、期望与方差

随机变量是把样本空间的每个结果映射到实数的函数（离散：如掷骰点数；连续：如身高）。离散分布列出每个取值的概率（骰子：$P(X=x) = 1/6$，$x \in \lbrace 1,\ldots,6 \rbrace$）；连续分布用概率密度函数描述，如正态密度

$$f(x) = \frac{1}{\sqrt{2\pi\sigma^2}} e^{-\frac{(x-\mu)^2}{2\sigma^2}}$$

期望是加权平均：$E(X) = \sum_i x_i P(X=x_i)$（离散）或 $E(X) = \int_{-\infty}^{\infty} x f(x)\,\mathrm{d}x$（连续）。方差度量离散程度：$\mathrm{Var}(X) = E[(X - E(X))^2]$，其平方根为标准差。

为什么期望是「决策的北极星」而方差是它的影子？期望效用理论下，理性决策最大化期望效用——期望是比较选项的第一顺位指标；但它只讲中心不讲波动，相同期望下风险厌恶者选方差小的（马科维茨 1952 年的组合选择理论：均值—方差平面上找有效前沿，夏普比率 = 超额收益/标准差）。注意期望的运算规则 $E(aX + bY) = aE(X) + bE(Y)$ 无条件成立（组合的期望收益是加权平均，无论成分是否相关），而方差规则 $\mathrm{Var}(aX + bY)$ 多出协方差项——**分散化能降风险的数学根源正是协方差项在成分不完全相关时变小**，一句话就是现代资产组合理论。

### 常用分布清单

离散：**伯努利**（成败一次，$P(X=1)=p$）、**二项**（$n$ 次独立伯努利的成功数，$P(X=k) = \binom{n}{k}p^k(1-p)^{n-k}$）、**泊松**（单位时间事件数，$P(X=k) = \frac{\lambda^k e^{-\lambda}}{k!}$）。连续：**均匀**（区间内等可能，$f(x) = \frac{1}{b-a}$）、**正态**（钟形，中心极限定理的极限形状）、**指数**（事件间隔时间，$f(x) = \lambda e^{-\lambda x}$，$x \geq 0$，无记忆性）。

为什么这张清单能覆盖经济学大半需求？因为它们各认领一类机制：伯努利认领「是/否」决策（就业与否、违约与否——离散选择模型的底座）；二项认领「重复试验的加总」（样本比例、选民分布）；泊松认领「稀有事件计数」（破产次数、专利申请、断供）；均匀认领「无知即等可能」（先验、随机数）；正态认领「许多小因素叠加」（下一节）；指数认领「等待时间」（失业持续期、两个交易间的间隔）。建模时选分布不是查表，是声明「数据由什么机制生成」。

### 大数法则与中心极限定理

**大数法则**：大量独立重复下，样本均值趋于期望值（弱、强两种形式）。**中心极限定理**：独立同分布随机变量之和（标准化后）趋近正态——哪怕原始分布不是正态。

为什么这两条定理是「经验研究能成立」的理由？大数法则回答「为什么样本平均值得信任」——抽样调查、A/B 测试、历史波动率的可信度全部押在它上面；中心极限定理回答「为什么误差总长成钟形」——测量误差、收益率近似、回归扰动项的正态假设，来源都是「许多独立小扰动的叠加」，而非「世界真的正态」。两条定理也各画一条红线：大数法则不保证「小样本也稳」（赌徒谬误正是把大数法则误用于短期）；中心极限定理要求独立同分布且方差有限——金融收益率有厚尾、波动聚集，正态假设低估极端风险，「黑天鹅」的统计配方就是滥用中心极限定理（关于厚尾的处置见下章与局限一节）。

## 问题与分析

### 圣彼得堡悖论说明了期望的什么缺陷？

赌局：掷硬币，首次正面在第 $n$ 次出现则赢 $2^{n-1}$ 元。期望 $\sum_{n} \frac{1}{2^n} 2^{n-1} = \sum_n \frac{1}{2} = \infty$，但没有人愿意付大价钱入场。伯努利的解法：人不最大化期望金额，而最大化**期望效用**——效用随财富递减（对数效用下该赌局期望效用有限）。这一步的深远在于：边际效用递减（第 4 章二阶条件）同时就是**风险厌恶的来源**——凹效用下，确定的 50 万好过五五开的 0 或 100 万，差额就是风险溢价；保险市场（用小保费换走大风险）与风险投资（用风险换溢价）在同一个解释框架内。期望的缺陷由此转化为经济学最有生产力的概念之一。

### 「这波行情是运气还是实力」如何用条件概率拆解？

设基金经理有真实选股能力 $p$（跑赢基准的概率），观察到他连续 $k$ 年跑赢。无能力者（$p = 0.5$）连续跑赢的概率 $0.5^k$ 随 $k$ 指数下降，但**基数的乘方效应**：万人规模的管理人中，纯靠运气也能批量产出「五连冠」——条件概率 $P(\text{有能力} \mid \text{连冠})$ 取决于先验（有能力者占比）与似然的比，而非连胜纪录本身。这是贝叶斯更新的标准应用，也是幸存者偏差的数学形态：只统计「还活着的管理人」，分母被悄悄抽走（第 11 章的选择偏差）。对经验研究的纪律含义：任何「显著成绩」都要先问分母——多少同行试过同样的事。

## 推导与例题

### 例 1：保险定价的三层拆解

某险种年出险概率 $p = 0.02$，出险损失 $L = 50$ 万元。**期望损失** $= 0.02 \times 50 = 1$ 万元——纯保费的下限。**公平保费** = 期望损失，保险公司收 1 万元在大量保单下收支相抵（大数法则保证波动被摊薄：$n = 10{,}000$ 份保单的赔付总额标准差 $\approx \sqrt{n p(1-p)} \cdot L \approx \sqrt{196} \times 50 = 700$ 万元，相对均值 1 亿元仅 7%）。**实际保费** > 1 万元，差额覆盖：管理成本、资本占用、逆风险选择余量。投保人愿意付高于 1 万元，因为凹效用下「确定的小损失」优于「2% 概率的大损失」（风险溢价）。三层拆解恰好对应三种角色：概率论（期望）、统计（波动）、偏好理论（凹效用）——一个保险合同，半部风险经济学。

### 例 2：二项分布与「样本多大才够」

民意调查 $n = 1000$ 人，支持率估计 $\hat{p}$ 的标准差 $\approx \sqrt{\frac{p(1-p)}{n}}$（$p \approx 0.5$ 时 $\approx \frac{0.5}{\sqrt{1000}} \approx 0.0158$）。$95\%$ 区间约 $\hat{p} \pm 1.96 \times 0.0158 \approx \hat{p} \pm 3.1$ 个百分点——「±3%」的行业惯例由此而来；样本翻四倍（$n = 4000$）才把误差减半（$\frac{1}{\sqrt{n}}$ 律），「精度靠堆样本很贵」的直觉立刻可算。方差公式 $\mathrm{Var}(\hat{p}) = \frac{p(1-p)}{n}$ 本身是二项方差除以 $n$ 的直接推论——下一章的抽样理论在此已埋好接口。

## 局限与后续

其一，**独立同分布是理想化**：经济时间序列有波动聚集（大事件连着大事件）、厚尾（极端值远超正态的预言）与结构突变——广义自回归条件异方差（Engle 1982，诺贝尔 2003）、厚尾分布（帕累托尾、幂律）与区制转换模型是实证工作的常规修正。其二，**期望效用被实验修正**：阿莱悖论（1953）与埃尔斯伯格悖论（1961）分别击中独立性与模糊厌恶，前景理论（1979）以「参照点依赖 + 损失厌恶 + 概率权重」重写选择公理，卡尼曼因此获 2002 年诺贝尔奖——「人是期望效用最大化者」从公理降级为基准。其三，**贝叶斯与频率之争**仍是统计推断的底层分野（下一章的开场白）；主成分与因子模型（第 8 章特征值的概率面）则把「从相关结构里提取隐变量」变成实证宏观与资产定价的主力工具。其四，**测度论的深水区**：连续时间金融（布朗运动、伊藤积分）与严格概率论（条件期望的公理化定义）超出本章，但方向已指明——本章的全部概念，在更深一层都会被重写一遍而不变其宗。
