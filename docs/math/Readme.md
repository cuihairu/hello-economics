# 经济学数学基础导读

这部分不是为了把数学单独学成一门课，而是为了回答一个更实际的问题：
经济学里常见的模型、图形、推导和实证分析，到底分别依赖哪些数学工具。

这套数学基础与四门课的对应关系、名著坐标与官方数据源，收拢在 [知识点主文档](/knowledge)。

## 你会在这里解决什么问题

- **我看到经济学公式时，连符号都读不懂怎么办**
  先学集合、逻辑、函数、数列和求和。
- **我知道图像怎么画，但不知道为什么「边际」「最优」「均衡」能这样分析**
  重点学微分、积分、矩阵和特征值。
- **我知道理论图形，但看不懂数据、回归和经验研究**
  重点学概率论和统计学。
- **我知道静态均衡，但看不懂动态调整过程**
  重点学数列极限、微分方程、特征值与特征向量。

## 建议学习顺序

1. [集合与逻辑](./集合与逻辑.md)
   学会区分研究对象、条件、结论和符号边界。
2. [数列与极限](./数列与极限.md)
   学会看长期趋势、收敛、稳态和无限期问题。
3. [常见求和公式](./常见求和公式.md)
   学会做多期加总、贴现和累计量计算。
4. [微分学基础](./微分学基础.md)
   学会边际分析、弹性分析和最优化。
5. [积分学基础](./积分学基础.md)
   学会把边际量累积成总量，把连续变化还原成总效果。
6. [微分方程](./微分方程.md)
   学会分析连续时间下的动态路径与稳定性。
7. [矩阵与行列式](./矩阵与行列式.md)
   学会处理联立方程组、多市场和多部门系统。
8. [特征值与特征向量](./特征值与特征向量.md)
   学会分析稳定性、主方向和二阶性质。
9. [线性空间与线性变换](./线性空间与线性变换.md)
   学会把多维变量和变换放进统一框架。
10. [概率论基础](./概率论基础.md)
    学会分析风险、不确定性和随机结果。
11. [统计学基础](./统计学基础.md)
    学会从数据中做描述、检验和回归分析。
12. [最优化方法与经济学应用](./最优化方法.md)
    学会把约束下的最优选择、现值贴现与弹性统一成一套求导语言。

## 每章分别服务于哪些经济学课程

**西方经济学**
- 需求、供给、效用、成本、厂商理论：主要依赖微分学、积分学。
- 一般均衡、福利分析：需要矩阵、线性空间、最优化基础。
- 宏观增长与动态分析：需要数列极限、微分方程、特征值。

**国际经济学**
- 贸易模型与要素流动：常用集合、函数、比较静态分析。
- 汇率与开放经济宏观：会用到微分、矩阵、动态稳定性分析。

**财政学**
- 税负分析、超额负担、最优税收：常用微分、积分和统计。
- 财政乘数、预算约束：常用求和、数列和联立方程。

**货币银行学**
- 利率、货币供求、资产组合选择：需要微分、概率、统计。
- 金融市场和动态调整：需要矩阵、特征值、微分方程。

**计量与实证分析**
- 概率论和统计学是核心。
- 矩阵、线性空间和特征值是回归、最小二乘、PCA 等方法的基础。

## 反查西方经济学后，这套数学基础是否覆盖

**已经覆盖的核心需求**
- [需求与供给](../western/需求与供给.md)：函数、均衡、弹性、比较静态、总收益变化。
- [效用论](../western/效用论.md)：边际效用、预算约束、无差异曲线、边际替代率、最优选择。
- [生产和成本论](../western/生产和成本论.md)：边际产量、边际成本、等产量曲线、边际技术替代率、成本最小化。
- [市场理论](../western/市场理论.md)：总收益、边际收益、边际成本、利润最大化、古诺均衡。
- [一般均衡论和福利经济学](../western/一般均衡论和福利经济学.md)：多市场联立、相对价格、MRS/MRTS/MRT、帕累托条件。
- [简单国民收入决定理论](../western/简单国民收入决定理论.md)：消费函数、乘数、联立均衡。
- [产品市场和货币市场的一般均衡](../western/产品市场和货币市场的一般均衡.md)：贴现、函数关系、方程组求解、IS-LM。
- [经济增长](../western/经济增长.md)：增长率、稳态、边际产出、动态稳定。

**此前轻度涉及、现已补齐的内容**
- **约束最优化（拉格朗日乘数法）**：消费者选择、厂商选择、一般均衡条件都可以用乘数法统一整理，见[最优化方法与经济学应用](最优化方法.md)。
- **现值与贴现**：资本边际效率、债券定价、跨期选择所用的贴现工具，同样在该章「现值与贴现」一节。

**如果按「看懂这本西方经济学」来说**
- 现有数学基础已经覆盖主体内容；想系统学扎实推导，直接读[最优化方法与经济学应用](最优化方法.md)。

## 如果你的目标不同，优先级也不同

**目标 1：先看懂本科经济学教材**
- 优先学：集合与逻辑、数列与极限、求和公式、微分学、积分学。

**目标 2：先看懂宏观和动态模型**
- 优先学：数列与极限、微分学、微分方程、矩阵、特征值。

**目标 3：先看懂回归和数据分析**
- 优先学：求和公式、矩阵、概率论、统计学。

## 学这一部分时要避免的误区

- 不要只背公式，不问「这个公式在经济学里回答什么问题」。
- 不要把图形直觉当成证明，很多结论背后依赖极限、导数或矩阵结构。
- 不要把「会算题」等同于「会建模」，真正重要的是知道为什么要用这个工具。
