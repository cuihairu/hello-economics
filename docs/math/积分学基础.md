# 积分学基础

> **本章核心问题**：已知每一单位的边际成本，如何还原总成本？已知需求曲线，「消费者总共愿意付多少」怎样从图形上读出来？当变化率已知、总量未知时，需要的工具就是积分——导数的逆运算。

## 本章脉络

积分与微分同源而生：牛顿与莱布尼茨的伟大综合（后世尊称微积分基本定理）在于发现「求变化率」与「求累积量」互为逆运算——这一发现把自古希腊阿基米德求积问题以来两千年的面积难题，一举化约为求原函数。定积分的严格基础则由 19 世纪补齐：黎曼 (1826-1866) 1854 年用「分割—近似—求和—取极限」定义了积分，把「曲线下面积」从几何直觉升格为分析对象；20 世纪勒贝格 (1875-1941) 的积分论进一步让概率论（第 10 章期望与方差的严格定义）获得坚实底座。

经济学接收积分学的路径与需求侧恰好对偶：微分学回答「已知总量，边际是什么」，积分学回答「已知边际，总量是什么」——而后者恰是福利分析的母题。1844 年，工程师出身的法国经济学家杜普伊 (1804-1866) 在计算公共工程的效用时首次用需求曲线下的面积度量「总支付意愿」，比马歇尔 (1842-1924) 正式提出消费者剩余早了半个世纪；今天教科书里的消费者剩余三角形、生产者剩余、无谓损失（哈伯格三角形），全部是定积分的几何投影。宏观一侧，拉姆齐 1928 年的最优储蓄问题、连续时间增长模型里的资本积累 $\dot{K} = sF(K) - \delta K$ 的累计效应，同样把积分当作日常语言。

本章路线：不定积分（原函数与积分常数）与定积分（区间上的累积值）的定义；基本积分规则（线性性、分部、代换）；常用积分表；几何意义；最后落到三大应用场——从边际量还原总量、需求曲线下的总支付意愿、连续时间下的流量累积。

## 核心概念

### 不定积分与定积分

不定积分是原函数的全体：若 $F'(x) = f(x)$，则 $\int f(x)\,\mathrm{d}x = F(x) + C$，其中 $C$ 为任意常数——因为常数的导数为零，原函数永远带着一个自由的平移量。定积分则是一个数：$\int_{a}^{b} f(x)\,\mathrm{d}x$ 表示函数在区间 $[a,b]$ 上的累积，几何上是曲线与 $x$ 轴之间的有向面积（$f \geq 0$ 时即通常意义的面积）。

为什么要区分「函数族」与「一个数」？因为经济学的两类问题各认领一个：从边际成本还原总成本要的是不定积分——但注意积分常数：$\int MC(q)\,\mathrm{d}q = VC(q) + C$ 只能恢复**可变成本**，固定成本那一项（常数）恰好是微分时被求导抹去的部分，须另行知道；而计算总支付意愿、消费者剩余要的是定积分——它在两个明确界限之间求累积，答案唯一。杜普伊与马歇尔的贡献可以读作：指出福利量对应的是后者。

### 基本积分规则

线性性：$\int c f(x)\,\mathrm{d}x = c\int f(x)\,\mathrm{d}x$，$\int (f \pm g)\,\mathrm{d}x = \int f\,\mathrm{d}x \pm \int g\,\mathrm{d}x$。分部积分：$\int u\,\mathrm{d}v = uv - \int v\,\mathrm{d}u$。代换法：对 $\int f(g(x))\,g'(x)\,\mathrm{d}x$，令 $u = g(x)$ 化为 $\int f(u)\,\mathrm{d}u$。

为什么分部积分在经济学里值得记住？因为期望、年金、贴现类问题常出现「多项式 × 指数」的乘积（如连续年金 $\int_0^{T} t\,e^{-rt}\,\mathrm{d}t$——持续时间与贴现因子的乘积），分部积分是唯一的解析通路；代换法则在「复合结构」中现身：需求以价格函数给出、又对数量积分时，换元能把两层函数拆开。两者的共同精神：把不认识的积分改写成积分表里的形状。

### 常用积分表

$$\int x^n\,\mathrm{d}x = \frac{x^{n+1}}{n+1} + C \ (n \neq -1), \qquad \int \frac{1}{x}\,\mathrm{d}x = \ln|x| + C, \qquad \int e^x\,\mathrm{d}x = e^x + C$$
$$\int \sin x\,\mathrm{d}x = -\cos x + C, \qquad \int \cos x\,\mathrm{d}x = \sin x + C$$

幂函数积分公式里 $n \neq -1$ 的例外单独成行（$\int x^{-1}\,\mathrm{d}x$ 落入对数）。定积分版本由牛顿-莱布尼茨公式给出：$\int_a^b f(x)\,\mathrm{d}x = F(b) - F(a)$，如 $\int_a^b x^n\,\mathrm{d}x = \frac{b^{n+1} - a^{n+1}}{n+1}$，$\int_a^b e^x\,\mathrm{d}x = e^b - e^a$，$\int_a^b \frac{\mathrm{d}x}{x} = \ln|b| - \ln|a|$，$\int_a^b \sin x\,\mathrm{d}x = -\cos b + \cos a$，$\int_a^b \cos x\,\mathrm{d}x = \sin b - \sin a$。

为什么幂规则里 $n = -1$ 的例外值得专门标出？因为它对应「比例增长」的累积：增长率恒定 $g$ 的量按 $e^{gt}$ 走，其对数线性；反过来，$\frac{1}{x}$ 的积分是对数——「翻倍耗时相等」的几何增长，其累计效应在经济学里（人口、通胀、技术进步）遍地都是，这条例外正是它们的积分入口。

### 几何意义与旋转体

$f(x) \geq 0$ 时 $\int_a^b f(x)\,\mathrm{d}x$ 是区间上的面积；积分还能算旋转体体积（圆盘法/圆环法）。例：$f(x) = x^2$ 在 $[0, 2]$ 上 $\int_0^2 x^2\,\mathrm{d}x = \left.\frac{x^3}{3}\right|_0^2 = \frac{8}{3}$。

为什么「面积」的读法比「算面积」更重要？因为经济学图形里的每块面积都有名义：需求线下是总支付意愿、线下与价格线上之间是消费者剩余、价格线与供给曲线之间是生产者剩余、两块剩余因扭曲而损失的部分是无谓损失。会积分的人看福利三角形的第三个顶点，看的是积分上下限——政策分析（税收楔子、价格管制）中三角形为何那样画、端点为何在那里，积分给出唯一权威的答案。

## 问题与分析

### 从边际量还原总量时，为什么会「丢」一块？

已知 $MC(q) = 4q + 3$，积分还原 $\int (4q+3)\,\mathrm{d}q = 2q^2 + 3q + C$。常数 $C$ 正是固定成本 $FC$——它是与产量无关的部分，边际成本里根本没有它的信息。推论：**仅凭边际成本无法区分两家固定成本不同的厂商**，而固定成本恰恰决定盈亏平衡与市场结构（自然垄断、进入壁垒，《西方经济学》第 4 章与第 7 章「市场失灵」的分析基础）。同理，边际效用积分还原总效用时会丢掉「消费为零时的效用水平」。积分不是全知工具：它恢复「随量变化的部分」，不变的部分须另行提供。

### 总支付意愿与总收入为什么不是一回事？

逆需求函数 $p(q)$ 是「第 $q$ 单位的边际支付意愿」。销售 $q$ 单位的总收入是 $R(q) = p(q) \cdot q$（每单位按同一价格出售），而消费者总支付意愿是 $\int_0^q p(x)\,\mathrm{d}x$（每单位按它自己的意愿价计价）。两者之差 $\int_0^q p(x)\,\mathrm{d}x - p(q)q$ 就是消费者剩余——统一定价下消费者「少付」的部分。数值对照见例 2：50 单位时总收入 2500，总支付意愿 3750，剩余 1250。一级价格歧视之所以能把剩余全部夺走，正因为逐单位定价时总收入才逼近总支付意愿（《西方经济学》第 4 章「市场理论」）。

## 推导与例题

### 例 1：从边际成本还原总成本

$MC(q) = 4q + 3$，已知固定成本 $FC = 5$。总可变成本 $VC(q) = \int_0^q (4x + 3)\,\mathrm{d}x = 2q^2 + 3q$（从 0 积到 $q$，天然排除了常数项——这是定积分处理「还原」问题的干净做法：直接积掉不确定性）。于是 $C(q) = 2q^2 + 3q + 5$，与本课第 4 章微分学例题的成本函数互为正逆运算的对照：微分丢掉常数，定积分从 0 出发还原可变部分。

### 例 2：总支付意愿与消费者剩余

逆需求 $p(q) = 100 - q$，售价 $P = 50$ 时销量 $q = 50$。

总收入：$R(50) = p(50) \cdot 50 = 50 \times 50 = 2500$。

总支付意愿：$\int_0^{50} (100 - q)\,\mathrm{d}q = \left.100q - \frac{q^2}{2}\right|_0^{50} = 5000 - 1250 = 3750$。

消费者剩余 $= 3750 - 2500 = 1250$——恰是三角形 $\frac{1}{2} \times 50 \times 50$ 的面积，几何与积分互相印证。若实施一级价格歧视，厂商逐单位索取意愿价，收入升至 3750，剩余归零；若对比竞争均衡（$P = MC$），则可进一步算出垄断造成的无谓损失——同一套积分，从描述走向规范评价。

## 局限与后续

其一，**「面积 = 福利」依赖一个强假设**：总支付意愿等于需求线下面积，要求需求曲线本身就是边际支付意愿的如实记录——收入效应显著时（吉芬品、必需品占比大的低收入家庭），普通消费者剩余与等价变差/补偿变差（希克斯 1939 年的修正度量）可以相差很远，精细福利分析须用后者。其二，**可积性并非必然**：原函数不能用初等函数表达的 $f$（如正态密度的不定积分）比比皆是——第 10 章概率里「查表求概率」正是因为解析积分不可行，数值积分（梯形法则、蒙特卡洛）因此成为实证经济学的基础设施。其三，**从定积分到测度论**：勒贝格积分把「分割定义域」换成「分割值域」，使不连续、病态函数同样可积，概率论的期望定义 $E(X) = \int x f(x)\,\mathrm{d}x$ 因此获得严格基础——这是第 10 章埋下的伏笔。至于把「累积」推到最优选择维度（动态规划、变分法），那是第 12 章最优化与后续动态经济学的地界。
