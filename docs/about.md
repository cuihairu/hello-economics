# 关于本站

Hello Economics 是一个经济学学习与参考站。它把西方经济学的主干课程整理成一条能读下去的线索：每个理论先回答「当时遇到了什么问题」，再看它如何展开，最后看后来被验证还是被修正。复习、备查、兴趣阅读，都可以从这里进。

## 内容范围

- **数学基础**是全部课程的前置工具课：微积分找最优点，线性代数解均衡，概率统计做检验，最优化方法把它们接到经济学问题上。
- **西方经济学**是主线：微观从供求讲到市场失灵，宏观从国民收入核算讲到学派分歧。
- **货币银行学、财政学、国际经济学、社会主义经济理论**四门专业课，各成一条线索。
- **名著篇**是十三本经典的书架，每本有一段短评；**术语篇**集中释义并可检索；**名人篇**画师承网络；**理论时间线**可拖动、缩放。

章节序列沿用国内通行教科书大纲；正文在教材骨架上重写为知识叙述，题库、背诵口诀一类应试材料已删去。

## 内容与数据说明

- 史实、年份与理论归属经站内人物词条、时间线与通行经济学史文献交叉核对；仍可能存在疏漏，欢迎指出。
- 公式以 LaTeX 排版，构建时做合法命令与定界符校验；文中示意图为自绘 SVG，标注出处的图形来自所引教材。
- 统计读数凡无唯一口径可考的，一律标注「约」或「以最新公布为准」。
- 各课程引用的教材与书目清单见[参考书目](/reference/参考书目)。
