# 理论时间线

经济学的每个理论都是对某个具体问题的回答：休谟要解释重商主义攒下的金银为什么留不住，凯恩斯要解释大萧条里为什么失业可以长期存在，卢卡斯要解释为什么按历史数据制定的政策总是失灵。这条线按出现顺序排列 {{ TIMELINE.length }} 个节点，每个节点都先回答「为什么是这个时候」。

## 这条线怎么用

**全览读疏密。** 默认档位把 1500 年至今压缩在一屏里——屏幕多窄都装得下整条线，只是节点会收细成短墨线，靠墨的多少读疏密。此时没有卡片：节点挤在一起的地方，通常就是同一个问题被反复重问的时代——1930 年代的萧条与计量、1970 年代的滞胀与理性预期、2008 年之后的货币理论修复。反过来，大片空档往往不是没有事件，而是当时的争论缺少能被观测的证据。

**放大读细节。** 换到「半世纪」「十五年」「五年」档位，或直接缩放（缩放以指针所在的年份为锚点，所以放大哪里由你手指下的年代决定）。密度足够时节点会展开成卡片，显示理论名与提出者；卡片按上下车道自动避让，互不遮盖。真避让不开的地方（1917—1921、1933—1941 这样连排的年代）宁可不印卡片，只留一个仍可点的节点——再放大一档卡片就散开了。屏幕越窄要放得越大：手机上的「半世纪」仍是一张疏密图，名字得到「十五年」才出现。

**点开会说明来由。** 点节点或卡片，下方的详情面板给出它要回答的问题、代表著作与站内对应章节；同一时间点上常常有不止一个理论，面板会把它们并列列出，这也是最有意思的部分：1936 年同时出现了《通论》与兰格模型，一个说市场经济会困在有效需求里，一个说计划当局可以试错模拟价格；紧接着的 1937 年，希克斯把前者画成 IS-LM，库兹涅茨的国民收入账户提交国会。理论、教科书形态与度量衡在同一年相遇，此后「刺激」才能被写进预算文件。

**先筛后看。** 顶部的领域标签是宏观、微观、货币、财政、国际、社会主义、数学与方法七组，计数标在标签上。筛到只剩一组时，同一时期的分歧会更容易看清：只看「货币」，这条线就从 1694 年英格兰银行成立（它发明的是「公共信用」而不是一家银行）一路走到 2014 年同一座房子承认「贷款创造存款」——这三百二十年里，「什么是货币」的答案换了两轮。

**需要通读时**，页面底部「按时期通读全部节点」那一段是同一份数据的文本形态，不依赖缩放，也便于逐条对照[术语篇](/glossary)与[名人篇](/people)。

## 关于这份数据本身

时间线的条目来自各章「理论的诞生与验证」一节，年份取的是**著作或机制出现的年份**，不是它被广泛接受的年份：科斯 1960 年的《社会成本问题》当年几无人引用，到 1970 年代经由斯蒂格勒的命名与推广才成为法律经济学的地基；理性预期 1961 年由穆思提出，直到 1976 年卢卡斯批判之后才真正改写宏观模型。所以这条线标出的是「问题被第一次认真回答」的时刻，而不是「共识形成」的时刻——后者要另画一条线，且通常滞后十五到二十年。
