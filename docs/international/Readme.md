# 国际经济学

这门课不是在背一串理论名字，而是在回答一个总问题：

**国家为什么要进行贸易和资本往来，开放经济中的价格、汇率和政策又怎样共同影响一国内外均衡。**

如果把整门课压成问题链，大致可以分成三层：

1. 贸易理论：为什么会贸易，比较优势从哪里来。
2. 贸易政策与开放：为什么会保护，关税和配额有什么影响。
3. 开放宏观：国际收支、汇率、资本流动和内外均衡怎么理解。

## 一、先抓这门课的总问题

- 国际贸易的利益从哪里来。
- 比较优势到底由技术还是要素禀赋决定。
- 为什么现实中仍然存在保护贸易和反倾销。
- 国际收支为什么会失衡，汇率为什么会变动。
- 开放经济中为什么更难同时实现内部稳定和外部平衡。

## 二、理论的诞生与验证

- **比较优势的第一次数据检验**：李嘉图 1817 年说出口模式由相对劳动生产率决定。麦克杜格尔（1951）用美英二十多个行业的出口数据验证：美国生产率领先的行业对英出口更强——比较优势通过了它诞生一百多年后的第一次系统检验。
- **里昂惕夫悖论（1953）**：H-O 定理预言资本充裕的美国应出口资本密集品。里昂惕夫用自己的投入产出表算出美国出口品反而更劳动密集，这个悖论引爆了人力资本、需求逆转、要素密度逆转等一系列修正——理论被自己的验证工具挑战的著名案例。
- **购买力平价的检验史**：卡塞尔 1918 年提出汇率由两国物价水平决定。数据结论分层：短期几乎不成立（汇率波动远大于物价差），长期弱成立。结论「短期不灵、长期趋同」促成了汇率决定的资产市场方法。
- **J 曲线效应**：货币贬值改善贸易收支需要先恶化后改善，因为进出口量对汇率变化的反应有时滞。多国数据支持这一形态——弹性分析法从理论变成了有形状的预测。
