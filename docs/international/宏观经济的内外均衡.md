# 第 8 章 宏观经济的内外均衡

> **本章核心问题**：一个开放经济既要国内有就业、物价稳，又要国际收支不失控——两个目标为什么常常打架？几件政策工具才够用？为什么说汇率制度、货币政策与资本流动「三者只能取二」？

## 本章脉络

内外均衡理论诞生于一个具体的政策困境。1951 年米德（Meade）在《国际收支》中提出「米德冲突」：在固定汇率与不使用支出转换政策的条件下，若经济处于失业与逆差并存（或通胀与顺差并存）的状态，单一的需求管理政策必然顾此失彼——扩需求救失业则逆差更糟，紧需求平衡收支则失业更糟。解药的理论基础由丁伯根 1952 年给出：要实现 N 个独立的经济目标，至少需要 N 个独立的政策工具。斯旺 1955 年把这套思想画成两条曲线的组合图（斯旺图），指定支出增减政策与汇率（支出转换）政策各管一头；蒙代尔 1962 年再往前推一步——工具对目标有相对有效性差异，财政工具调内部最有效、货币工具调外部最有效，按比较优势指派工具（「有效市场分类」），两个目标两件工具即可收敛。这套指派思想嵌进 IS-LM-BP 框架就是蒙代尔-弗莱明模型（1962—1963）：给定汇率制度与资本流动性，财政与货币政策的效果被系统地形化——固定汇率下财政政策有力而货币政策无力（因被汇率干预抵消），浮动汇率下正相反。三元悖论是这条理论线的终点站：货币政策独立、汇率稳定与资本自由流动三者不可兼得（克鲁格曼 1999 年以《萧条经济学的回归》将其通俗化，「不可能三角」由此进入大众词汇；弗兰克尔同年亦作系统表述）。本章先补两个概念铺垫（贸易乘数、边际进口倾向——开放使乘数变小、内外均衡的耦合变紧），再依次呈现内外均衡的过程与政策搭配。

## 核心概念

### 贸易乘数

贸易乘数指乘数理论在对外贸易研究中的作用，探讨对外贸易与国民收入和就业之间的关系。在贸易乘数公式中，它是边际储蓄倾向与边际进口倾向之和的倒数：

$$K_T = \frac{1}{MPS + MPM}$$

（$MPS$ 为边际储蓄倾向，$MPM$ 为边际进口倾向）。贸易乘数原理表明：在边际储蓄倾向与边际进口倾向之和小于 1 的条件下，增加出口有利于提高有效需求、增加国民收入和就业。

乘数的机制是收入的多轮循环：出口增加 100 元成为国内收入，收入获得者按边际倾向消费、储蓄、购买进口，其中储蓄与进口是「漏出」——钱离开收入循环的水池；每一轮漏出一部分，循环持续到新增需求被漏出耗尽，累计新增国民收入恰为 $100/(MPS+MPM)$。封闭经济的投资乘数是 $1/MPS$，开放后多了进口这条漏出口，贸易乘数必然更小——开放度越高的经济，每单位出口刺激留给本国的部分越小（新加坡、卢森堡这类高开放小型经济体的乘数很小，美国、日本这类大陆经济的乘数相对大）。这就是「内外耦合」的第一个通道：出口通过乘数改变国民收入，国民收入再通过边际进口倾向反作用于贸易差额——任何内部政策都会经由这条链「泄漏」到外部账户上，内外均衡由此连成一张网。

### 边际进口倾向

边际进口倾向是指进口的变动对引起这种变动的收入变动的比率，即国民收入每增加一单位所引起的进口增加量，通常以 $m$ 表示。国民收入变动之所以影响进口量：收入增加时消费（尤其是对品质更高、更多依赖进口的商品的消费）增加，向外国购买更多商品即进口量增加；反之则减少。边际进口倾向大，则每一单位增量国民收入中用于进口的比重大，乘数效应对经济的刺激作用较小；反之则较大。

这个系数的政策分量比它的定义朴素得多。其一，它是「进口的漏出率」：中国的边际进口倾向低于多数同等开放度经济体，同样的出口扩张带来的国内收入循环更长——这是出口导向战略在中国格外有效的微观原因之一。其二，它决定「他国增长能否搭便车」：一国收入增长、进口增加，成为贸易伙伴的出口需求——大国边际进口倾向高，其增长就外溢给全世界，2000 年代中国加入 WTO 后的扩张性增长对全球大宗商品与资本品市场的拉动是当代最大规模的「进口外溢」。其三，它是政策协调的接口：各国同时紧缩时，彼此的进口需求一起收缩，乘数链全球共振放大衰退（1930 年代的教训、2009 年贸易骤降的回声）——「以邻为壑」的机制正藏在边际进口倾向里。

## 问题与分析

### 贸易乘数公式的推导

**符号**：$Y$ 国民收入，$C$ 消费，$I$ 投资，$G$ 政府支出，$X$ 出口，$M$ 进口，$S$ 储蓄，$T$ 税收，$K_T$ 贸易乘数，$MPS$ 边际储蓄倾向，$MPM$ 边际进口倾向。

**推导**：开放经济的均衡要求总需求等于总供给——$Y = C + I + G + X$（支出面），$Y = C + S + T + M$（收入面）。令税收等于政府支出（$T = G$），化简均衡条件：

$$I + X = S + M$$

即「注入口之和等于漏出口之和」：投资与出口注入收入循环，储蓄与进口漏出循环。对均衡取增量：

$$dI + dX = dS + dM$$

引入边际倾向 $dS = MPS \cdot dY$、$dM = MPM \cdot dY$，代入：

$$dI + dX = (MPS + MPM) \cdot dY$$

解出国民收入的变化：

$$dY = \frac{dI + dX}{MPS + MPM}$$

假设投资与储蓄不变（$dI = dS = 0$），仅考虑出口变化的带动：

$$dY = \frac{dX}{MPS + MPM},\qquad K_T = \frac{dY}{dX} = \frac{1}{MPS + MPM}$$

无储蓄漏出时（$MPS = 0$）简化为 $K_T = 1/MPM$。公式含义：漏出率（储蓄+进口）是乘数的分母——$MPS$ 或 $MPM$ 越大，$K_T$ 越小。与投资乘数 $K_I = 1/MPS$ 对照，贸易乘数通常更小（漏出渠道多一条）。整个推导把「出口为什么能带动就业」的凯恩斯直觉变成了可核算的公式，也为政策协调提供了定量语言（评估出口下滑对 GDP 的冲击、估算刺激计划的进口外泄）。

### 不可能三角（三元悖论）的含义

不可能三角定律（三元悖论）的主要内容：三角的每一边表示一种政策目标——独立的货币政策、汇率的稳定性（实践中指固定汇率）与资本的完全自由流动，三者各有其吸引力，但任何国家不能同时实现三边；每一组「两边组合」对应一个顶角所代表的制度形态，即完全的资本控制、货币联盟（或货币局）与完全的浮动汇率。

![图 8-1 不可能三角定律图解](../img/exercises/international/8-1.png)

图 8-1 为不可能三角图解。若一国货币政策完全独立、资本又自由跨国流动，便不能实行固定汇率，汇率必须浮动——给定资本完全自由流动，固定汇率与货币政策独立只能取其一。逻辑内核是套利与货币主权的不相容：固定汇率+资本自由流动下，国内利率必须紧跟锚定国利率，否则利差引发资本流动冲击固定平价——货币政策的独立性名存实亡（1992 年欧洲汇率机制危机是标准案例：英国想降息救衰退、德国央行不肯降，资本外逃冲垮英镑平价，「黑色星期三」后英国退出并转向浮动）。三边的现实组合各有代表：美国选择货币政策独立+资本自由流动（放弃汇率稳定，自由浮动）；中国香港选择汇率稳定+资本自由流动（放弃货币独立，联系汇率制，利率被动跟随美元）；中国大陆长期选择货币政策独立+汇率稳定（放弃资本完全自由流动，实施资本项目的有限开放）。三元悖论的价值在于把「选哪种汇率制度」从偏好问题变成约束问题——任何汇率制度的争论最终都要落到「你放弃哪一角」。1997 年亚洲金融危机与 2008 年全球金融危机后，雷伊（Rey）提出「全球金融周期」的修正：即使实行浮动汇率，全球风险偏好（美国的货币政策周期）也会同步传染各国的金融条件，独立的货币政策在金融开放下仍受掣肘——「三元悖论可能变成二元困境」。但这一修正并未推翻三角的会计恒等，而是说明「资本自由流动」这一边本身会输出约束：放弃得越彻底，被全球金融周期带走的政策空间越多。

## 综合论述

### 一国宏观经济内外均衡的过程与政策搭配

**（1）内外均衡的含义与调节政策**

内部均衡指国内总供给等于总需求，即实现资源充分就业、物价稳定，并获得有保证的增长；外部均衡指一国与外部经济体之间的经济流入量与流出量相等，国际收支处于平衡状态。同时实现内外均衡较为困难，失衡时需调整恢复，以求经济平衡增长。

调节政策分三类。支出变化政策：通过改变社会总支出调节总需求，包括财政手段、货币手段与汇率政策。支出转换政策：能够影响贸易商品的国际竞争力、通过改变支出构成使本国收入相对支出增加的政策，如汇率调整、关税、出口补贴、进口配额限制。经济管制：以法律法规直接控制经济运行，使经济向预定方向发展（外汇管制、进口审批等——见效直接但扭曲资源配置，是前两者的补充而非替代）。

**（2）固定汇率制下的调节过程**

![图 8-2 固定汇率制条件下内外均衡实现过程](../img/exercises/international/8-2.png)

假设内外均衡只取决于有形贸易的变化，可用 IS-LM-BP 模型分析。图 8-2 中经济处于通货膨胀与国际收支逆差并存的状态：先用紧缩财政政策治理通胀，IS 曲线左移至过 E 点的 $IS^{'}$，国内均衡达成；但利率随之下降、资本流出，国际收支逆差反而加大——再用紧缩货币政策调整，LM 曲线左移至过 E 点的 $LM^{'}$，利率回升、资本回流、进口需求收缩，经济恢复内外同时均衡。这个「财政先动、货币补台」的次序正是蒙代尔指派方案的图形化：两件工具先后就位，两个目标各自收敛。

**（3）浮动汇率制下的自动调节**

若实行浮动汇率，调节过程不同：发生内外失衡时，浮动汇率制度产生自动调节——汇率变动同时作用于商品市场（相对价格改变进出口）与资本市场（预期与套利资金流动），商品、资本与外汇三个市场经一定过程自动趋向均衡，对内对外均衡无须政策逐项干预。自动化的代价是汇率本身的波动（超调、失调与金融稳定问题，见「局限与后续」）。

**（4）斯旺图与政策搭配**

![图 8-3 斯旺图](../img/exercises/international/8-3.png)

图 8-3 中 BOP 线代表在一定的汇率与国内支出组合下的一国外部均衡，线以上为对外顺差、以下为逆差；F 线代表同条件下的国内均衡，F 线左边为衰退与失业、右边为过度就业与通胀；两线交点是内外均衡同时达成的唯一点。四象限构成失衡的诊断表：第Ⅰ象限通胀与顺差并存，按蒙代尔搭配应取紧缩财政+扩张货币；第Ⅱ象限衰退与顺差并存，扩张财政+扩张货币；第Ⅲ象限衰退与逆差并存，扩张财政+紧缩货币；第Ⅳ象限通胀与逆差并存，紧缩财政+紧缩货币。搭配的原则即「有效市场分类」：财政工具对内部均衡相对有效（管家里），货币工具对外部均衡相对有效（管外面）——利率既作用于国内需求又作用于资本流动，货币政策因此一身而二任、对外更直接。以第Ⅲ象限（衰退+逆差）为例走一遍组合逻辑：扩张财政刺激国内需求创造就业（治内），紧缩货币提高利率吸引资本流入并抑制进口（治外），两政策方向相反所以能同时推进而不互相抵消——这正是米德冲突在「两工具」条件下的解。

斯旺-蒙代尔框架的当代应用仍以这一逻辑运转：2010 年代中国「积极的财政政策+稳健偏紧的宏观杠杆约束」应对「经济下行压力+资本外流压力」的组合，其内在语法与四象限表并无二致；1992—93 年欧洲汇率机制危机则是反例教材——英国在固定汇率约束下不能自主降息救衰退，汇率这一角锁死了货币工具，政策搭配无从谈起，最终以退出机制、转向浮动收场。

## 局限与后续

本章框架的边界与它的假设一一对应，当代研究在这四处推进。其一，**蒙代尔-弗莱明模型的微观化**：MF 的静态预期与价格刚性假设在 1970 年代受到卢卡斯批判，Obstfeld-Rogoff 1995 年的 Redux 模型以跨期最优与垄断竞争重建开放宏观（「新开放宏观经济学」），MF 的结论大多在新框架内保留定性有效性但获得了福利评估能力——政策效果的评判标准从「产出是否恢复」升级为「福利是否改善」。其二，**金融渠道的显形**：2008 年后研究发现，汇率渠道之外存在强大的「全球金融周期」——美元融资条件、跨境银行杠杆与风险偏好同步驱动各国的信贷与资产价格（Rey 2013），浮动汇率并不能隔离外部冲击，三元悖论的「浮动换独立」折扣增大；宏观审慎政策（资本流动管理工具的现代形态）因此被 IMF 纳入政策工具箱，与货币政策并列。其三，**最优货币区理论的回归**：蒙代尔 1961 年的最优货币区理论（生产要素流动性、经济开放度、产业多样性等标准决定一群国家是否适合同舟共济）在欧元诞生时被反复引用，欧债危机（2010—2015）中「财政联盟缺位的不对称冲击」恰恰验证了其预警——内外均衡理论在「放弃本国货币」的极端情形下以危机的形式补课。其四，**中国语境的持续检验**：资本项目有限开放+有管理浮动+货币政策独立的中国组合是三角的「中间解」，其可持续性（中间制度消失论的对立面）、跨境资本流动宏观审慎框架（全口径跨境融资宏观审慎、逆周期因子）的设计，都在改写教科书上「三选二」的离散选择图景。内外均衡理论的下一段史，大概率由「金融开放的速度与次序」来写。
