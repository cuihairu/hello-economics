# 宏观经济模型演进

> **本页核心问题**：宏观经济学为什么需要一整套模型，而不是一个「万能模型」？从 45° 线到 IS-LM、AD-AS，再到菲利普斯曲线、增长模型与开放经济——每一代模型回答了什么问题，又暴露了什么新问题，才让下一代不得不登场？

宏观课程的正文章节按教材顺序逐个讲解模型；本页做另一件事——把模型串成一条演进的线。你会看到：每个模型都是为了回答上一个模型无法回答的问题而诞生的，假设的每一次放松（引入利率、引入价格、引入预期、引入时间、引入对外部门）都是一次对现实的逼近，也是一次新的暴露。读完本页再回头看各章，模型的「分工」会一目了然。

## 演进主线一图流

```
凯恩斯革命（1936）
   │  问题：大萧条为什么出现大规模失业？
   ▼
45° 线模型 ── 只看产品市场，价格与利率都固定
   │  暴露：利率由什么决定？货币政策有用吗？
   ▼
IS-LM（希克斯 1937）── 两个市场联立，利率内生
   │  暴露：价格固定，无法分析通胀与供给
   ▼
AD-AS ── 价格内生，需求与供给会师
   │  暴露：通胀的动态过程与预期从哪来？
   ▼
菲利普斯曲线（1958 → 1968 预期革命）
   │  暴露：这只解释波动，长期增长由什么决定？
   ▼
增长模型（哈罗德-多马 1939 → 索洛 1956 → 内生增长 1980s）
   │  暴露：以上全是封闭经济
   ▼
蒙代尔-弗莱明（1962-1963）── 开放经济与汇率制度
```

一条线贯穿始终：**模型不是对错之分，而是分工之分**——没有最好的模型，只有最适用于眼前问题的模型。

## 第一站：45° 线模型——产品市场的短周期

1936 年《通论》出版时，凯恩斯手里并没有一张今天教科书上的图。把「有效需求决定产出」画成最简形式的是后来的教科书传统：只保留产品市场，价格固定（$P=1$），利率外生给定，经济中有闲置资源。

**均衡条件**是总产出等于总支出：

$$Y = AE = C + I + G$$

线性消费函数 $C = \alpha + \beta Y_d$（$\beta$ 为边际消费倾向）代入后，均衡收入由外生支出决定。这个模型最锋利的产出是**乘数**：投资增加一元，收入增加不止一元——因为新增收入会变成下一轮消费。

$$\Delta Y = \Delta C + \Delta I = \beta\,\Delta Y + \Delta I \quad\Longrightarrow\quad \Delta Y = \frac{\Delta I}{1-\beta} = \frac{\Delta I}{MPS}$$

乘数是把「需求决定产出」从口号变成可计算命题的第一步。但模型的代价立刻显现：利率被假定为给定的，于是「央行降息能不能刺激经济」这个问题在模型里根本不存在；价格固定，于是通货膨胀不存在。这两个缺口就是下一站的入口。

## 第二站：IS-LM——两个市场的联立

希克斯 1937 年的《凯恩斯先生与「古典学派」》把《通论》压缩成两个市场、两条曲线：产品市场均衡给出 **IS**（利率与收入负相关），货币市场均衡给出 **LM**（利率与收入正相关）。

**IS 的来历**：把储蓄-投资均衡 $S(Y) = I(r)$ 写成线性形式。消费函数 $C = \alpha + \beta Y$ 推出储蓄函数 $S = -\alpha + (1-\beta)Y$，投资函数 $I = e - dr$，令二者相等：

$$Y = \frac{\alpha + e}{1-\beta} - \frac{d}{1-\beta}\,r$$

利率下降 → 投资增加 → 经乘数放大为更大的收入，这就是 IS 向右下方倾斜的全部内容。

**LM 的来历**：凯恩斯的流动性偏好理论把货币需求拆成交易/预防需求（随收入增）与投机需求（随利率减）：$L = kY - hr$。货币供给外生 $\frac{M}{P}$，令供求相等：

$$Y = \frac{h}{k}\,r + \frac{1}{k}\cdot\frac{M}{P}$$

收入越高交易性货币需求越大，在货币供给固定时只能靠更高的利率「挤出」投机需求来平衡——LM 因此向右上方倾斜。LM 还有两个极端区域：利率极低时投机需求无穷大（**流动性陷阱**，LM 水平，货币政策失效）；利率极高时投机需求为零（**古典区域**，LM 垂直，货币政策完全有效）。

**两条曲线的交点**同时决定利率与收入。政策分析在这个框架里第一次变得清晰：

- **财政政策**移动 IS：$G$ 增加使 IS 右移，$Y$ 增、$r$ 增——利率上升抑制部分私人投资，即**挤出效应**；
- **货币政策**移动 LM：$M$ 增加使 LM 右移，$Y$ 增、$r$ 降。

IS-LM 统治了战后宏观经济学三十年。但它的关键假设——价格固定——在 1970 年代的通胀面前再也守不住：模型里没有价格变量，就没有供给，也就没有滞胀的位置。

## 第三站：AD-AS——让价格与供给入场

把 IS-LM 里的价格从「1」变成变量，**总需求曲线**就自动浮现：价格 $P$ 上升 → 实际货币供给 $\frac{M}{P}$ 下降 → LM 左移 → 利率上升 → 投资与收入下降。所以 AD 向右下方倾斜。对线性 IS-LM 联立消去 $r$，可以解出显式的总需求函数：

$$Y = \frac{h(\alpha+e)}{kd + h(1-\beta)} + \frac{Md}{\left[kd + h(1-\beta)\right]P}$$

第二项的分母里有 $P$——价格越高，均衡收入越低。这背后是三个并行的机制：凯恩斯效应（利率渠道）、庇古效应（实际余额渠道，价格上升稀释财富压低消费）、以及开放经济中的蒙代尔-弗莱明效应（价格上升削弱出口竞争力）。

**总供给曲线**是 AD-AS 相对 IS-LM 真正的新增资产，其形状取决于货币工资的伸缩性：

- **短期**（工资向下刚性）：生产函数 $Y = AN^{\alpha}$，厂商雇佣到 $\frac{W}{P} = MP_N$。价格 $P$ 上升而 $W$ 不动时，实际工资下降、就业与产出上升——短期 AS 向右上方倾斜，可写成 $Y = \gamma P^{\theta}$（$\theta = \frac{\alpha}{1-\alpha} > 0$）。
- **长期**（工资完全伸缩）：价格变动最终被货币工资追平，实际工资与就业回到充分就业水平，产出锁定在潜在产出 $Y^*$——长期 AS 是垂直线。

**短长期均衡的调整机制**由此清楚：产出低于潜在水平时失业超过自然率，工资下行压力使短期 AS 逐渐右移回 $Y^*$；高于潜在水平时反向。财政与货币政策在短期移动 AD（改变产出与价格），在长期只改变价格——「长期中货币中性」的教科书版本。

**滞胀**是这个框架最有名的应用：不利供给冲击（1970 年代石油危机）使 AS 左移，产出下降的同时价格上升——需求管理陷入两难，刺激需求保产出则加剧通胀，压通胀则加深衰退。正是这场两难把「预期」推上了舞台中央。

## 第四站：菲利普斯曲线——通胀与失业的替代及其兴衰

1958 年菲利普斯用英国 1861-1957 年的数据发现失业率与货币工资增长率稳定负相关；1960 年萨缪尔森与索洛把它改写成通胀与失业的替代关系——一条为政策服务的「菜单」：用多一点通胀换少一点失业。

弗里德曼（1968）与费尔普斯的批判终结了这份菜单：替代关系只在**预期未被兑现**时存在。扩张性政策压低失业 → 工人发现实际工资下降 → 要求补涨名义工资 → 失业回到自然率，只剩更高的通胀。把预期写进价格调整方程：

$$\pi_t = \pi_t^e + h\,\frac{Y_t - Y_f}{Y_f}$$

长期中 $\pi_t^e$ 追平实际通胀，失业率与任何通胀水平都不再相关——长期菲利普斯曲线垂直于自然失业率。1970 年代的滞胀（通胀与失业同时升高）被这个框架干净地解释：预期通胀上移叠加油价冲击，曲线整体右移。今天的新凯恩斯主义菲利普斯曲线（粘性价格下的前瞻预期版本）仍是央行分析通胀动态的标配工具。

## 第五站：增长模型——从波动转向长期

波动解释完，另一组问题浮出水面：为什么有的国家富、有的国家穷？增长能持续吗？

**哈罗德-多马**（1939/1946）是第一个系统的增长模型，也是一次警示：在资本-产出比 $v$ 固定的假设下，增长率 $G = \frac{s}{v}$。充分就业的稳定增长要求实际增长率、有保证的增长率与自然增长率三者相等（$G_A = G_W = G_N$）——这条「刃锋」条件几乎不可能满足，稍有偏离就会发散。刀锋上的增长理论邀请了对假设的放松。

**索洛**（1956）把资本-产出比变成变量：资本与劳动可替代、边际报酬递减。人均资本积累方程

$$\dot{k} = sf(k) - (n+\delta)k$$

把增长拆成储蓄带来的「资本深化」与人口增长加折旧的「资本广化」。稳态 $sf(k^*) = (n+\delta)k^*$ 之下，人均产出长期增长只剩技术进步率这一个来源。三条经典结论由此而来：储蓄率只改变稳态水平不改变稳态增长率；条件收敛（在其他参数相近时穷国增长更快）；黄金律 $f'(k) = n+\delta$ 刻画使人均消费最大的稳态。索洛的软肋同样明显：技术进步是外生的——增长最重要的来源被放在了模型之外。

**内生增长**（1980s，罗默等人）正面接住这个软肋：让技术由经济系统内部的决策（研发投入、知识积累）决定。最简的 AK 模型 $Y = AK$ 取消了资本边际报酬递减，持续增长不再依赖外生技术；政策第一次改变了长期增长率——教育投资、研发补贴、知识产权保护不再只是水平效应，而是增长效应。

## 第六站：开放经济——蒙代尔-弗莱明与不可能三角

最后一个缺口是国界。蒙代尔（1963）与弗莱明（1962）把 IS-LM 扩展到开放经济：产品市场里净出口依赖实际汇率 $NX(\varepsilon)$，利率通过资本流动与汇率挂钩，完全资本流动下国内利率被钉在世界利率 $r = r^*$。

结论浓缩成一张表（小型开放经济、资本完全流动）：

| 汇率制度 | 财政政策 | 货币政策 |
|---------|---------|---------|
| 固定汇率 | 非常有效 | 无效 |
| 浮动汇率 | 无效 | 非常有效 |

机制都是同一个：**资本流动倒逼货币当局**。固定汇率下，财政扩张推高利率、吸引资本流入，央行必须买入外汇投放本币，LM 被动右移，扩张被放大；货币扩张压低利率、资本外流，央行不得不回收本币，扩张自我抵消。浮动汇率下正好相反：财政扩张推高利率、本币升值、净出口回落，挤出完全来自外部；货币扩张则通过贬值放大净出口，效果倍增。

把汇率制度、资本流动与货币政策独立性画成三角形，就是**蒙代尔不可能三角**：三者最多同时取二。坚守货币独立与汇率稳定就得管制资本（中国曾经的选择）；要资本自由流动与货币独立就得让汇率浮动（美国）；要汇率稳定与资本流动就得放弃独立货币政策（中国香港的联系汇率制）。

## 模型体系对比

| 模型 | 坐标平面 | 内生变量 | 关键假设 | 主要用途 |
|------|---------|---------|---------|---------|
| 45° 线 | (Y, AE) | 均衡收入 | 价格、利率固定 | 乘数与需求管理直觉 |
| IS-LM | (Y, r) | 收入、利率 | 价格固定 | 短期政策分析（财政 vs 货币） |
| AD-AS | (Y, P) | 收入、价格 | 短期工资刚性 | 波动、滞胀、长短期区分 |
| 菲利普斯曲线 | (π, u) | 通胀动态 | 预期形成方式 | 通胀-失业替代的边界 |
| 哈罗德-多马 | — | 增长率 | v 固定 | 增长的内在不稳定性 |
| 索洛模型 | (k, 增长) | 稳态资本 | 边际报酬递减 | 收敛、储蓄与技术的作用 |
| 内生增长 | — | 长期增长率 | 知识/报酬非递减 | 政策对增长的作用 |
| 蒙代尔-弗莱明 | (Y, e) | 收入、汇率 | 资本流动 | 汇率制度下的政策搭配 |

按时间维度看：超短期（价格完全刚性）是 IS-LM 的领地，中期（价格可调）交给 AD-AS 与菲利普斯曲线，长期（充分就业、价格完全伸缩）是增长模型的世界；按开放维度看，封闭经济模型到蒙代尔-弗莱明补全对外部门。

## 局限与后续

这条演进线到 1980 年代为止，此后的进展在同一逻辑上继续：

- **理性预期与卢卡斯批判**（1976）：模型参数会随政策规则改变，「用历史参数评估新政策」在逻辑上不成立——DSGE 从方法论上重写了上面的全部模型，但 IS-LM 与 AD-AS 作为教学与快速政策直觉的地位未曾动摇。
- **真实经济周期与新新古典综合**：波动不再只来自需求，技术冲击与价格粘性的争论在 DSGE 框架内合流。
- **零利率与流动性陷阱回归**：2008 年之后流动性陷阱从教科书脚注变成主要经济体的现实，IS-LM 的凯恩斯区域重新获得解释力。
- **全球金融周期**（Rey 2013）：资本自由流动下小国的货币政策独立性比不可能三角预言的更少——「三元悖论」其实是个二元悖论。
- **行为宏观与异质性**：代表性主体与完全理性假设被行为修正与异质性主体模型（HANK）补充，消费与通胀动态的微观基础更贴近数据。

没有「最好」的模型，只有「最适用」的模型——看清每个模型假设了什么、放开了什么，才能在具体问题面前选对工具。这既是本页的收束，也是阅读正文章节时始终带着的问题意识。
