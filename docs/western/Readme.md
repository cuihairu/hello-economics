# 西方经济学

这门课不是在背零散概念，而是在回答一个总问题：

**市场中的消费者、厂商和政府，怎样通过价格、产出和政策相互作用，决定资源配置和经济波动。**

---

## 西方经济学的发展故事

在进入具体章节之前，先了解这门学科如何演变而来，有助于理解各个理论的来龙去脉。

### 第一幕：重商主义——那个迷恋金银的时代（16-18世纪）

16世纪的欧洲，国家像守财奴一样认为**财富就是金银珠宝**。重商主义者的想法很简单：多卖东西给外国人，少买外国人的东西，就能赚取金银。这开启了早期贸易保护理论的先河。

### 第二幕：亚当·斯密与"看不见的手"——经济学诞生（1776年）

1776年，亚当·斯密发表《国富论》，提出了革命性观点：**分工创造财富，"看不见的手"引导市场运作**。

> "我们每天期望的晚餐，不是来自屠夫、酿酒师或面包师的恩惠，而是来自他们对自身利益的追求。"

每个人追求自身利益，却像被一只"看不见的手"指引，不知不觉促进了整个社会的利益。**政府别管太多，让市场自己运作！**

### 第三幕：李嘉图与"比较优势"（1817年）

大卫·李嘉图提出了**比较优势理论**：即使你什么都比别人强，也应该专注做自己最擅长的事，然后交换。这成为自由贸易的理论基础。

### 第四幕：萨伊定律——供给创造需求（19世纪初）

萨伊宣称："产品会自己为自己创造需求。"一个人赚的钱最终会花出去变成别人的收入，**不会出现普遍的生产过剩**。这个观点统治了经济学界一百多年。

### 第五幕：边际革命——让经济学变成真正的科学（1870年代）

杰文斯、门格尔、瓦尔拉斯几乎同时想到了同一个问题：**钻石为什么比水贵？**

答案是**边际效用**——价值取决于多得到一单位的满足程度。从此，经济学引入了边际分析和微积分，开始用科学方法研究经济问题。

### 第六幕：马歇尔——供求曲线的发明者（1890年）

马歇尔整合前人理论，发明了著名的**供求交叉图**。当供给曲线和需求曲线相交时，就是均衡价格。这个框架至今仍是微观经济学的核心。

### 第七幕：大萧条与凯恩斯革命——经济学的"大分裂"（1936年）

1929年大萧条打破了"市场会自动调节"的美梦。凯恩斯指出：

> "从长远看，我们都死了。"

他的核心观点：
- **工资和价格有"粘性"**，不会立即调整
- **"有效需求不足"**导致经济萧条
- **政府应该干预**，通过财政政策刺激经济

**凯恩斯革命**之后，经济学分裂成微观和宏观两大分支。

### 第八幕：货币主义的反击——弗里德曼的挑战（1970年代）

1970年代"滞胀"（经济停滞+通货膨胀）让凯恩斯理论陷入困境。弗里德曼带领货币主义学派反击：

> "通货膨胀始终是货币现象。"

政府管得太多反而把经济搞乱了，货币政策应该遵循"单一规则"——货币供应量稳定增长。

### 第九幕：理性预期革命（1970-80年代）

以卢卡斯为代表的新古典宏观经济学提出**理性预期**：人们会利用所有信息理性预测未来并调整行为，**系统性的宏观经济政策无效**。

### 第十幕：新凯恩斯主义——两只手并用（1980年代-至今）

新凯恩斯主义承认人是理性的，但市场是不完美的。价格粘性、工资粘性、信息不对称等因素导致市场失灵，**短期内政府政策仍然有效，但要谨慎使用**。

**核心争论仍在继续**：政府该不该干预市场？市场会不会失灵？如何平衡效率与公平？

今天的经济学已不再是非此即彼的争论，而是**不同学派相互借鉴、共同发展**。每一场革命，都是对前人思想的继承与超越。

## 一、先抓这门课的总问题

- 为什么需求曲线向右下方倾斜，弹性为什么重要。
- 厂商怎样在成本约束下实现利润最大化。
- 完全竞争、垄断和市场失灵分别意味着什么。
- 国民收入、利率和价格水平怎样在宏观上形成均衡。
- 财政政策和货币政策怎样影响总需求、总供给和经济增长。

## 二、理论的诞生与验证

这门课里的重要理论几乎都诞生于危机，也都在经验检验里被修正过：

- **菲利普斯曲线（1958）**：菲利普斯用英国百年数据发现失业与工资增长率负相关，60 年代被当成政策菜单——多要点通胀就能买到就业。70 年代滞胀（高通胀与高失业并存）直接证伪了这条菜单，弗里德曼与费尔普斯加入预期后把它修正为「短期倾斜、长期垂直」。一次反例推动了整个宏观的预期革命。
- **沃克尔紧缩（1979-1982）**：美联储主席沃克尔用近乎实验的方式验证货币数量论——狠狠收紧货币，通胀从 13% 跌到 3%，代价是失业率破 10%。货币主义对了一半：通胀确实是货币现象，但代价（牺牲率）比激进版本预言的大。
- **卢卡斯批判（1976）**：用历史数据估计的模型参数，在政策规则改变后会失效——因为人会调整预期。此后宏观模型被迫全部重写为带微观基础的形式，这是理论被逻辑（而非数据）修正的例子。
- **农产品弹性**：「谷贱伤农」是需求价格弹性 < 1 的经典验证：丰收压低价格的幅度大于销量增加的幅度，总收入反而下降。
