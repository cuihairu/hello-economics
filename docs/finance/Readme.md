# 财政学

这门课不是在背收支概念，而是在回答一个总问题：

**为什么市场经济中仍然需要政府财政，政府又怎样通过支出、税收、国债和预算完成公共治理。**

如果把整门课压成问题链，大致可以分成三层：

1. 财政职能：政府为什么存在，财政为什么有正当性。
2. 财政收支：钱怎么花、钱怎么收、为什么还要借钱。
3. 财政约束：预算、赤字和可持续性怎么把财政管起来。

## 一、先抓这门课的总问题

- 为什么市场经济条件下仍需要财政。
- 财政支出为什么会不断扩大。
- 税收怎样体现公平与效率的平衡。
- 国家为什么不能只靠税收，还要发行国债。
- 预算和赤字为什么是现代财政管理的核心。

## 二、理论的诞生与验证

- **庇古税与碳定价**：庇古 1920 年提出外部性可以用税收矫正。这个构想沉睡半个世纪后成为现实：欧盟碳排放交易体系（2005 起）与各国碳税就是「庇古税」的最大规模实验，硫排放交易的美国实践更早（1990 清洁空气法修正案），排放量显著下降为理论提供了证据。
- **公共物品与搭便车实验**：公共物品的非排他性会导致供给不足。公共品博弈实验（Marwell & Ames 1981 等）系统观察到搭便车行为，但也没有完全搭便车——人们的条件合作倾向反过来修正了纯自利假设。
- **拉弗曲线的证据边界**：「税率太高反而收不到税」在逻辑上成立（两个极端税率都收不到税），但供给学派 80 年代据此预测减税会自我买单，美国的赤字走势否定了强版本；边际税率极高的人群（如瑞典富人）确实会迁移避税，弱版本在数据里成立。一条曲线的两半命运，是「理论正确≠政策正确」的教材案例。
- **国债负担与李嘉图等价**：政府发债还是征税？巴罗 1974 年复兴李嘉图等价（发债=未来税收，理性家庭会储蓄对冲）。经验检验大体否定其强形式——人们的消费确实对减税退税有反应——说明跨期最优化假设只近似成立。
