# 文档与源码一致性审计

本文件按《文档与源码一致性审计规范》落表：抽取文档里的可验证技术主张，逐条对源码取证，只登记三类差异——超前（文档写了，源码没有）、缺失（源码已有，文档没写）、不符（两边都有但口径不一致）；修法一律以源码为准改文档。新批次发现差异就向表中追加行，不删旧记录。

首轮审计：2026-10-10（todo 进度日志第五十批）。第二轮：2026-10-27（CI 测试门禁修复批，登记 B1–B3）。

## 审计面

- 仓根元文档：`README.md`、`README.zh.md`、`PRODUCT.md`、`STYLE.md`、`todo.md` 头部约束
- 站点元页面：`docs/zh/about.md`、`docs/zh/index.md`（原 `docs/about.md`、`docs/index.md`，随中文内容迁入 `/zh/` 语言位，见 B2）
- 设计批注：`.impeccable/surfaces/docs-index-md.md`、`.impeccable/surfaces/docs-timeline-md.md`

审计对象限于技术主张：路径、命令、配置、计数与约束。章节正文的史实、年份与理论归属由内容批次的章级审计负责，不在本表。
