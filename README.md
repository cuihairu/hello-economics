# 经济学综合复习导航

这份首页只做一件事：把整套资料的使用顺序和入口整理清楚。

如果你时间不多，直接按这个顺序走：

1. 先看试卷结构，知道每科大概值多少分。
2. 再按学科入口进入各科 `Readme`，先抓总问题和复习顺序。
3. 然后用真题和预测卷做检验。
4. 最后用各科“高频大题速背骨架 -> 考前1小时速背版 -> 最后10题/最后20题”压缩记忆。

## 一、试卷结构

这部分以近年常见公开资料整理，先看整张卷子的稳定结构，不再把题量机械拆到每一科，避免误导。

## 六、流程

### 资格审查

操作平台：[学信网](https://www.chsi.com.cn/)

- 注册账号
- 查看招生信息
- 提交学位申请
- 采集照片与指纹
- 打印资格审查表
- 完成资格审查

### 报名考试

操作平台：[中国教育考试网](https://tdxl.neea.edu.cn/)

- 网上报名
- 资格审查
- 网上缴费
- 打印准考证
- 全国统考

### 所需物品

- 身份证
- 准考证
- 黑色签字笔
- 2B 铅笔

> 英语考试卷一到时间会收走，所以要在规定时间内完成并填涂答题卡。
