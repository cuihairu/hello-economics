# 第 10 章 结束语：经济全球化趋势

> **本章核心问题**：经济全球化的驱动因素是什么？全球化对各国经济有何影响？如何应对全球化带来的挑战？

## 一、名词解释

### 经济全球化

联合国贸发会议对经济全球化定义如下：“全球化是世界各国在经济上跨国界联系和相互依存日益加强的过程，运输、通讯和信息技术的迅速进步有力地促进了这一过程。

”国际货币基金组织为经济全球化下的定义则是：“跨国商品、服务贸易及国际资本流动规模和形式的增加，以及技术广泛迅速传播使世界各国经济的相互依赖性增强。”经济全球化是现代经济的一个动态过程，是社会经济发展到一定阶段的产物。

---

**【通俗理解：地球变成一个村】**

**核心思想**：世界各国就像邻居一样，你中有我，我中有你。

---

**【一、什么是全球化？】**

**通俗比喻**：地球从"七大洲"变成了"一个村"

| 以前 | 现在 |
|------|------|
| 各国各玩各的 | 全村一起做生意 |
| 中国人用华为，美国人用苹果 | 大家都用iPhone + 微信 |
| 美国感冒，中国打喷嚏？不可能 | 美国打个喷嚏，全球都感冒 |

**核心变化**：**距离消失了，边界模糊了**

---

**【二、全球化的三大表现】**

| 方面 | 以前 | 现在 |
|------|------|------|
| **商品** | 国产货为主 | 淘宝买遍全世界 |
| **资本** | 钱在国内转 | 钱满世界跑（外资、海投） |
| **信息** | 写信、发电报 | 微信、TikTok秒通全球 |

---

**【三、全球化的动力】**

**① 技术进步（推土机）**

| 技术 | 作用 |
|------|------|
| **互联网** | 信息瞬间传遍全球 |
| **集装箱船** | 运费降到地板 |
| **飞机** | 当天可达世界任何地方 |

**② 资本逐利（发动机）**

| 逻辑 | 资本去哪里？ |
|------|-------------|
| 哪里便宜去哪里 | 越南开厂 |
| 哪里赚钱去哪里 | 投资美股 |
| 哪里安全去哪里 | 瑞士存钱 |

**③ 制度松绑（开门）**

| 变化 | 例子 |
|------|------|
| 降低关税 | 中国加入WTO |
| 放松管制 | 欧盟一体化 |
| 保护产权 | 各国争相吸引外资 |

---

**【四、全球化的好处】**

| 好处 | 例子 |
|------|------|
| **消费者** | 便宜商品任你挑 |
| **生产者** | 全球市场随便卖 |
| **工作者** | 外企、出海机会多 |
| **创新者** | 技术传播快 |

**一句话**：蛋糕做大了！

---

**【五、全球化的坏处】**

| 问题 | 例子 |
|------|------|
| **贫富差距** | 资本家赚翻，工人工资停滞 |
| **产业空心化** | 发达国家工厂搬到发展中国家 |
| **金融传染** | 美国次贷危机 → 全球金融危机 |
| **文化冲击** | 好莱坞、肯德基遍地开花 |
| **主权削弱** | 跨国公司比小国家还有钱 |

**一句话**：风险也全球化了！

---

**【六、中国的全球化之路】**

| 阶段 | 策略 | 结果 |
|------|------|------|
| **1980-2000** | 引进外资、出口导向 | "世界工厂" |
| **2001** | 加入WTO | 出口爆发式增长 |
| **2010s** | 一带一路 | 开始资本输出 |
| **2020s** | 双循环 | 内外兼顾 |

---

**【七、一句话记忆】**

> **经济全球化** = "地球变小了，大家变近了" = 你中有我，我中有你，谁也离不开谁
